# Trinidad and Tobago Postal Context

This directory is an M1 metadata contract, not a production postcode pack.

TTPost states that six-digit postal codes are available for all addresses. The digits identify a postal district, a delivery loop, and finally a building or zone. TTPost also describes a code as narrowing to a small area or point and says the last pair can identify a group of addresses or a large institution. Consequently, a syntactically valid code is neither a guaranteed area nor public geometry.

M2 remains blocked until a current complete typed assignment denominator, compatible reuse rights and eligible real Polygon/MultiPolygon artifacts are fixed and verified through the TT API/app. Postal districts, routes, administration, address points, buildings and AGID cells are not substitute postal areas. Exact address and building display requires a separate rights-cleared civic-address-to-building relation.
