# Gibraltar Postal Context seed

This directory is a metadata-only M1 contract for GI. It contains no raw official download, address-register row, real address, personal/customer data, land/cadastre record, or production geometry.

The current country-specific M2 definition is `M2_current_gibraltar_generic_postcode_visualization`. UPU August 2026 establishes exactly one generic whole-country code, `GX11 1AA`; the older country sheet preserves `E/V` only as a domestic addressing exception. Neither fact creates an official postal boundary.

A Gibraltar-wide display could be published only as `virtual` context after explicit territory-boundary reproduction, derivative, publication and serving rights are established. The reviewed HM Government Geoportal disclaimer withholds that inference. OAR addresses, WFS availability, government maps, parcels, buildings, points, buffers and synthetic fixtures never satisfy M2.

See [the source review](../../../../reports/postal-context-m2/gi-source-review-2026-08-30.json) and [technical review](../../../../docs/postal-context-gibraltar-m2.md).
