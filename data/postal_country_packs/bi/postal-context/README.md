# Burundi Postal Context

This directory is a metadata-only, fail-closed research contract. Current UPU evidence classifies Burundi among countries that do not require postal codes, and the November 2025 Burundi addressing sheet uses P.O. box, commune and province without a postcode. It contains no postcode assignments, raw source body, real address or production geometry and enables no BI runtime descriptor.

The older BI country pack remains draft planning material. Its administrative/locality records and synthetic cells are not RNP postcodes or postal areas.
