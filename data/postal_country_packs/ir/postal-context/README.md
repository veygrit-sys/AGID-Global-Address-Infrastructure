# Iran postal-context contract

Status: **M1_metadata; M2_licensed_assignment remains blocked**.
The named M2 criterion formalizes the existing ten-digit, non-area, forwarding
prefix, P.O. Box/poste restante, GNAF, privacy, temporal and jurisdiction rules.
All nine existing hard blockers remain unchanged.

See [the IR M2 review](../../../../docs/postal-context-iran-m2.md),
`m2-source-review.json`, `repository-manifest.json` and `source-profile.json`.
The latter remains the original metadata-only source contract.

The source review records live public-entry failures, not a national absence
finding or licence ban. The searchable UPU copy is not a currently retrieved,
digest-pinned source. A five-digit prefix, full place identifier, certificate,
GNAF query, point or NSDI boundary never automatically supplies an official
postal polygon or address/building relation.

No source rows, private addresses, recipients, residents, customer/owner/title
data, coordinates or geometry are included. Existing fixtures remain
synthetic and cannot satisfy M2. Actual data publication outside AGID Git and
restricted access require explicit approval. AGID cells stay an independent
index, linked only through independently evidenced, versioned crosswalks.
