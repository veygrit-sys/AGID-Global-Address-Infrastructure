# Belarus Postal Context pack

This directory is an M1 metadata contract. Belarus M2 requires a current complete Belpost assignment and the actual current NCA postal-zone layer with explicit public redistribution, derivative and API rights. The public cadastral-map viewer, postcode/address results, post-office points and synthetic fixtures are not distributable postal polygons.

The country-specific review is pinned by `m2-source-review.json`. Exact downloaded audit inputs stay outside Git. Production promotion remains blocked until an approved immutable artifact drives the real AGID API and app postcode-search-to-translucent-area path.
