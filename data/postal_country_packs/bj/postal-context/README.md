# Benin Postal Context

This directory is a metadata-only, fail-closed research contract. Current UPU evidence classifies Benin among countries that do not require postal codes, and the November 2025 Benin addressing sheet uses a delivery-office identifier, P.O. box, locality and telephone number without a postcode. It contains no postcode assignments, raw source body, real address or production geometry and enables no BJ runtime descriptor.

Agency names, departments, communes, localities, delivery-office identifiers, P.O. boxes, civic-address fields and AGID cells remain separately typed context. None is a La Poste du Bénin postcode or postal area.
