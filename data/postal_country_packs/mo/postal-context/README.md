# Macao address-context contract (MO)

This is an M1 metadata contract, not a production dataset or a new repository.
CTT does not use a local postcode system. Its `000000` online-form workaround is
not an assignment. Official postal code and postal geometry remain `null`/`none`.

The country-specific M2 target is `M2_scoped_address_context`: a real licensed
street/civic-address release, explicit source identity/edition/rights, separate
building relations, reproducible quality checks, approved immutable data artifacts
and actual MO AGID loader/API verification. None is replaced by synthetic tests.

Existing MO address fields and Chinese/Portuguese metadata remain intact. Legacy
DSCC IDs are preserved, with current DSSCU authority from 2026-06-01 recorded.
Mapping reproduction/publication requires permission and may involve fees; no
purchase or agreement was made. HTML shells are not licences or datasets.

See [review](../../../../docs/postal-context-macao-m2.md), the source profile,
and `m2-source-review.json` for exact URLs and SHA-256 receipts. The generic
Postal Context runtime remains disabled for MO until real no-postcode data and
its descriptor/API are verified. No raw pages, addresses or cadastral data are
included here.
