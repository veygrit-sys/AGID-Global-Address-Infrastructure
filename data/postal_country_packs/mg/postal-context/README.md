# Madagascar Postal Context contract seed

This directory contains metadata and synthetic conformance fixtures for the
planned external `agid-postal-mg` repository. It contains no Paositra Malagasy
postcode rows, real addresses, personal data, land records or production
geometry.

The dated UPU addressing sheet documents a three-digit code placed before the
postal town, with the first digit based on a historical province and the final
two digits on a department/Fivondronana. The current operator website confirms
postal services and a `101 ANTANANARIVO` self-address, but no reviewed current
nationwide assignment artifact or postcode boundary release was found.

Consequently a full code has `geometry: none` until separately authorized
boundary evidence exists. Historical province semantics, current administrative
boundaries, offices, community lists, land, civic addresses, buildings and AGID
remain separate evidence partitions.
