# Mexico Postal Context M2 source notice

This pack covers the latest geographic postcode release currently published by Servicio Postal Mexicano (SEPOMEX) through Mexico's official datos.gob.mx catalog. The catalog contains 32 state SHP resources titled 2025, with dataset metadata updated on 2026-01-29 and source DBF dates of 2026-01-05. The exact CKAN response and all 32 ZIP bodies were retrieved on 2026-09-01; 129,105,086 bytes across 33 exact bodies are bound by SHA-256 in `source-profile.json`.

The source release contains 35,898 features and 35,898 distinct five-digit postal codes. It declares Creative Commons Attribution 4.0. Attribution: Servicio Postal Mexicano (SEPOMEX), “Códigos postales por entidad federativa”, 2025 state resources, accessed through datos.gob.mx.

The public runtime does not bundle raw source ZIPs. It publishes a reproducible derived display artifact: GDAL reprojects the official Lambert Conformal Conic source to EPSG:4326, applies explicit validity repair and a base 100 m topology-preserving simplification, and rounds to six decimal places. A final 0.0012-degree topology-preserving display simplification was applied to 28,014 features only when its relative area delta stayed at or below 1%; 7,884 features were retained at the prior detail. The resulting display accuracy is conservatively declared as 250 m. When the base simplification collapsed a small source feature, the pipeline restored that code from its transformed original surface; 228 features used this fallback. Thirty-five invalid simplified surfaces used raw-original surface fallback, with ten selected GEOS repairs; eight strict-parser surfaces used dedicated GEOS fallback and four remaining zero-area or touching/overlapping-hole cases received bounded repairs (maximum relative area delta 0.000258). Mixed-dimension GeometryCollections retain Polygon or MultiPolygon surface members only. Lines and points are discarded, never buffered or converted into an area. No gap, Voronoi, interpolation or model surface is generated.

Every runtime feature is therefore labelled `derived`, with the official SEPOMEX mapping release retained as assignment and postal-geometry authority. The 2025 geometry release is the latest official spatial publication located during this run; it is not represented as a 2026-09-01 delivery-current national assignment catalog. The separately downloadable Correos de México national catalog states restrictions on commercialization and is not redistributed or used to broaden these polygons.

Postal code → polygon → address context authority remains separated. This pack contains no address, building, parcel, owner, recipient, customer, query log, delivery entitlement or land-right data. Raw source ZIPs and the exact CKAN response are excluded from Git and must be reacquired from their pinned official URLs before reproduction.
