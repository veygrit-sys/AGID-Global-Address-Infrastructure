# Antigua and Barbuda Postal Context contract

This directory is a metadata-only M1 review. It records the current UPU
postcode-optionality classification, designated-operator identity, dated
addressing example, national postal authority, reuse boundary and AG-specific
M2 rule. It contains no raw official body, address, customer record, code row
or production geometry.

The sibling `data/postal_country_packs/ag` Postal Forge pack remains draft
synthetic planning material: 48 synthetic locality IDs, 12 boundary slots,
246 planning cells and zero official municipality records. None is an Antigua
and Barbuda Postal Service identifier or postal perimeter.

M2 requires a current complete operator-authorized identifier/exception/non-
area denominator, compatible rights, a fixed valid real Polygon/MultiPolygon
artifact for every drawable identifier and verification through the real AG
API and application. A no-required-postcode policy, office, route, P.O. box,
island, parish, locality, point, buffer, hull, Voronoi/raster or planning cell
cannot be promoted as an official postal area.
