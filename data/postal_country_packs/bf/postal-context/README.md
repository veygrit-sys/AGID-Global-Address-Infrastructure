# Burkina Faso Postal Context

This directory is a metadata-only, fail-closed research contract. La Poste Burkina Faso and the UPU confirm a current five-digit postcode system, but the reviewed public sources do not publish a rights-compatible complete assignment denominator or real postal Polygon/MultiPolygon artifact. It contains no raw source body, bulk postcode rows, real address or production geometry and enables no BF runtime descriptor.

The older BF country pack remains draft planning material. Its administrative/locality records and synthetic cells are not La Poste Burkina Faso assignments or postal areas. Commune, quartier and agency lookup results, BP/BV numbers, administrative boundaries and AGID IDs stay separately typed.
