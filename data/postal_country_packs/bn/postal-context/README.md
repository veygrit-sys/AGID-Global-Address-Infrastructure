# Brunei Postal Context seed

This directory contains metadata, policy and synthetic fixtures, not a released
postcode or address dataset. BN is **M1_metadata**; the source-attested national
M2 criterion is not met.

See the [country M2 review](../../../../docs/postal-context-brunei-m2.md),
[manifest](repository-manifest.json) and [source-review contract](m2-source-review.json).
The historical SKN-hosted booklet and current PosBru operator evidence are kept
separate. Observed routing assignments have no polygon or exact civic/building
authority; no real source rows, PDFs or personal data are bundled here.
