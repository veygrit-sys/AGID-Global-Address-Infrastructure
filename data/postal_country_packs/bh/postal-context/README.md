# Bahrain Postal Context contract seed

M1_metadata only. M2_assignment still requires complete, rights-cleared,
editioned postcode-block assignments and non-spatial P.O. box rules.
M3 geometry/civic addresses and M4 exact buildings remain separate stages.

The [M2 source review](../../../../docs/postal-context-bahrain-m2.md) inspected
27 public-landmark points and the official reuse documents. Twenty block labels
are not twenty proven postcodes. The metadata bbox is not a postal polygon,
and landmark counters and coordinates are not civic/building identifiers.

The portal-linked government open-data licence v1.0 can cover eligible open
datasets on other government sites. Exact applicability, attribution/date,
transformation, disclaimer, sublicence, removal and privacy conditions still
matter; null per-dataset licence fields are not proof of no reuse rights.
Controlled certificates, CPR/subscriber/ownership data are not released by this
metadata seed or by a generic reference to open-government licensing.

Only aggregate evidence, hashes, schema and review metadata are bundled. No
original point rows, names, coordinates, subscriber data, addresses or source
PDFs are included. Synthetic fixtures cannot promote M2. No new country
repository, public dataset destination or real runtime descriptor was created.
