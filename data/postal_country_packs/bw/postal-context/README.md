# Botswana Postal Context

This directory is a metadata-only, fail-closed research contract. The current UPU evidence classifies Botswana among countries that do not require postal codes. The UPU Botswana addressing sheet and the current BotswanaPost page use a P.O. Box or private bag plus locality without a postcode. It contains no postcode assignments, raw source body, real address, production geometry or enabled BW runtime descriptor.

P.O. boxes, private bags, plots, streets, districts, wards, villages, localities and AGID cells remain separately typed address context. None is a BotswanaPost postcode or postal area.
