# AGID Open Historical Alias Source Scope Fixtures

This repository is a synthetic source-completeness fixture for the historical
names and aliases layer. It proves that former names, alternate spellings, and
local aliases can be evaluated as their own source scope without implying a
global all-place-name completeness claim.

## Scope

- Synthetic alias records only.
- Source metadata and place links use `example.test` fixture URLs.
- Alias evidence is source-bound to Wikidata-style, GeoNames-style, and open
  reference metadata.
- No raw addresses, recipients, witness values, private keys, proof secrets, or
  production credentials are stored here.

## Non-claims

- This is not a complete country, territory, city, alias, address, carrier, or
  delivery dataset.
- Passing the historical-alias layer does not prove that an obsolete name is
  current, official, legally valid, safe for delivery, or accepted by a carrier.
- Alias matching must not override source freshness, official status, boundary,
  routing, access, privacy, or manual review gates.
