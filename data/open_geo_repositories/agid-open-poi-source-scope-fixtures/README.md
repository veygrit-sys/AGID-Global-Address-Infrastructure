# AGID Open POI Source Scope Fixtures

This repository is a synthetic source-completeness fixture for the POI layer.
It proves that POI evidence can be evaluated as its own source scope without
claiming global place-name, delivery, address, legal, or carrier completeness.

## Scope

- Synthetic POI records only.
- OSM-style links and open-reference source metadata are placeholders for gate
  behavior.
- No raw addresses, recipients, private identifiers, production credentials, or
  live provider traffic are included.

## Non-Claims

- This is not a complete country, territory, city, POI, address, carrier, or
  delivery dataset.
- Passing the POI source layer does not prove opening hours, endorsement,
  access rights, legal status, route access, or carrier support.
- The fixture must not be used as a production gazetteer or address-validation
  corpus.
