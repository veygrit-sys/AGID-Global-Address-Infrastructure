# AGID Open Natural Feature Source Scope Fixtures

This repository is a synthetic source-completeness fixture for the natural
feature layer. It proves that natural feature evidence can be evaluated as its
own source scope without claiming global place-name, access, safety, boundary,
environmental, legal, delivery, or carrier completeness.

## Scope

- Synthetic natural feature records only.
- GeoNames-style, OSM-style, and open-reference links are placeholders for gate
  behavior.
- No raw addresses, recipients, private identifiers, production credentials, or
  live provider traffic are included.

## Non-Claims

- This is not a complete country, territory, natural-feature, address, carrier,
  access, route, boundary, environmental, or safety dataset.
- Passing the natural-feature layer does not prove safe access, legal access,
  current environmental conditions, precise geometry, route availability, or
  delivery reachability.
- The fixture must not be used as a production gazetteer, routing corpus, or
  emergency-response source.
