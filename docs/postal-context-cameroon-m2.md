# Cameroon Postal Context M2 review

Status: **blocked at M1 metadata; excluded from current postcode data creation**. M2 is not achieved.

The UPU Universal DataBase September 2025 no-postcode list, in the file updated August 2026, explicitly includes Cameroon. The official UPU 07/2002 CM sheet shows BP 6000 followed by YAOUNDE, without a postcode. A current MINPOSTEL page identifies Campost as the public operator and lists 42 authorized private operators, but publishes no postcode assignment denominator or postal geometry. A MINESUP government page labels 54190 as Adresse postale: B.P. and gives BP 1739 Yaoundé-Cameroun; these are P.O.-box identifiers, not five-digit postcodes. The false five-digit CM rule in the English shipping profile has therefore been changed to not-used.

Five exact UPU, MINPOSTEL and MINESUP bodies were checked offline by byte length, SHA-256, PDF page count where applicable and content markers (938,084 bytes total). UPU copyright/database restrictions and Cameroon government all-rights-reserved notices are recorded. Raw bodies are excluded from Git.

The CM gate rejects arbitrary digits, BP/P.O.-box values, offices, routes, Points, administrative polygons, buffers, hulls, Voronoi/raster cells, AGID cells, neighbouring-country assignments and Hugging Face/libpostal output as CM postal truth. OSM may provide separately attributed place, address, building or administrative context only. Detailed building display still needs a separate rights-cleared identity and explicit geometry relation.

The actual app ran at http://127.0.0.1:3036/. A live Yaoundé, Cameroon search rendered GCM3T yaounde Cameroon, Rue 7.082, Étoug-ébé, Yaoundé, Centre, Cameroun, two map canvases and independent AGID CM0224YJ5QS9. This is meaningfully more detailed than a country/postcode result, but Photon marked it high and ambiguous; it is not asserted as an authoritative building-footprint relation. The unmocked request GET /api/v1/postal/CM/54190?geometry=geojson returned 404 Postal Context country is not supported; no postal-area notice or translucent postal overlay rendered.

In-app Browser setup failed before navigation with a Windows ACL helper error, so deterministic Playwright was used. Its full-page screenshot and assertions passed, but local image viewing failed with Windows error 206; manual visual inspection is explicitly false. Polygon quality is therefore a fail-closed result: there is no legitimate CM postcode polygon to inspect or improve, and no administrative/BP/model proxy was produced.

M2 can be reconsidered only after a competent authority introduces a current CM postcode system, releases a complete versioned assignment denominator and exact real Polygon/MultiPolygon geometry under AGID-compatible processing, derivation, redistribution and serving rights, and the real CM API/app/browser path passes all state, fit, styling, clear and re-search checks. Retry after the pending-country sweep or 2026-12-03, unless such an official release appears earlier.
