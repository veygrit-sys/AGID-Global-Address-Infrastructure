# Suriname Postal Context M2 review

## Result - excluded from postcode data creation; M2 remains unmet

The Universal Postal Union September 2025 Universal DataBase lists Suriname among countries which do not require postal codes. Its Suriname addressing sheet (03/2005) shows the documented address structure without a postcode line. The current SURPOST site identifies the operator and states all rights reserved. SR therefore has no valid postcode search key or postal Polygon/MultiPolygon to promote.

## Address and ID detail without inventing postal authority

The AGID address definition now removes the misleading postcode field and follows the documented street-plus-house-number, sublocality and city structure. District is retained only as independently typed context. Recipient, organization, street, house number, sublocality, city, district and country remain separate address/context identifiers; none becomes a postcode or postal area. A future building display requires a separately rights-cleared civic identity and explicit building relation.

## Exact evidence and reproducibility

Three exact official bodies totaling 720,221 bytes were fixed outside Git with SHA-256. The offline inspector accepts only those filenames, sizes and digests, validates the two PDF page counts and Suriname/no-postcode/address markers plus SURPOST identity and rights markers, and emits only aggregate zero-production receipts. Missing, renamed, additional or changed bodies fail closed. Raw source bodies remain outside Git.

## Application and polygon-quality boundary

Shared deterministic contracts still cover normalization, loading, no-match, multiple candidates, API failure, invalid geometry, Polygon/MultiPolygon-only rendering, fit, translucent fill, clear outline, clear and re-search. They do not prove an SR runtime. The Browser connection failed during Windows ACL setup. Since there is no legitimate SR postcode input or postal polygon, no browser area E2E, positive visual result or synthetic surface is claimed. Existing draft SR planning cells are explicitly excluded from promotion.

## Rights, retry and promotion gate

Public access to UPU/SURPOST reference pages does not grant processing, derivation, redistribution or public-serving rights for a postal dataset. Keep SR blocked and do not re-check before 2026-12-02 or before the pending-country sweep completes, unless SURPOST or UPU announces a postcode system. Provider contact, registration, authentication, terms acceptance, contract, payment, protected-data access, destination creation, publication or deployment needs explicit approval.

M2 can be reconsidered only after a current complete authoritative assignment denominator, compatible rights, fixed real postal Polygon/MultiPolygon artifacts and actual SR API/app visual verification exist.
