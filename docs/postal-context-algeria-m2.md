# Algeria Postal Context M2 review

Status: **blocked at M1 metadata**. Algeria has a current five-digit postcode system, but M2 is not achieved.

The UPU July 2002 Algeria sheet defines five digits and historical delivery-area/wilaya semantics. The current UPU August 2026 table confirms Algeria still uses numeric 99999. Executive Decree 19-258 is stronger authority: article 4 says Algérie Poste exclusively determines postcodes, and the final address line carries the postcode plus commune. The live Algérie Poste directory exposes named establishments, codes, addresses and hours by wilaya; separate entries such as 16230 and 31118 are mobile postal establishments, while some establishment rows have blank codes. These public views are useful observations, not a complete immutable denominator of every current assignment, alias, correction, validity interval, exception and area/non-area object.

Five exact UPU and Algerian-government bodies were fixed by byte length and SHA-256 (1,151,046 bytes). The one-page UPU country sheet, 12-page current general table and five-page decree were text-inspected; five relevant pages were deterministically rendered. The Algérie Poste host timed out from the source-capture process, so its cached public directory results were reviewed but no operator response bytes were promoted. No provider contact, registration, authentication, terms acceptance, contract or payment was attempted. Raw PDF, HTML, PNG and application screenshots are not committed.

No rights-cleared official postal Polygon/MultiPolygon release was found. A postal establishment or mobile service code is not automatically an area. Wilaya, daïra and commune polygons, office/address points, routes, P.O. boxes, organizations, INCT products, OSM, buffers, hulls, Voronoi/raster cells, Hugging Face/model output and AGID cells were not promoted. Postal geometry quality remains zero official, zero derived, zero virtual and zero production-eligible records.

The repository now has a deterministic DZ gate that requires current Algérie Poste authority, a complete finite denominator, compatible rights and a same-code explicitly authoritative postal Polygon/MultiPolygon before postcode-to-AGID area linkage can pass. The six-line decree structure supports source-qualified address context more detailed than the postcode. Exact building display still requires an independent rights-cleared address-to-building relation; postcode containment, office text, proximity and model score are candidates only.

The actual app ran at http://127.0.0.1:3039/. Searching Algérie Poste, Bab Ezzouar, Algeria selected the USTHB post office at BP 32, Boulevard de l'Université, Bab Ezzouar from OSM via Photon, rendered two map canvases and independent AGID DZ02A83TH4JX. The result was high but ambiguous/needs-review and was not asserted as an authoritative postal area or exact building. The unmocked GET /api/v1/postal/DZ/16024?geometry=geojson returned 503 Postal Context pack is unavailable; no postal-area notice or translucent postal overlay rendered.

In-app Browser setup failed before navigation with a Windows ACL helper error. Deterministic Playwright fallback passed, but local PNG viewing failed with Windows error 206. Manual visual inspection is explicitly false; deterministic rendering is not presented as browser E2E or visual approval.

Hugging Face, libpostal and other open-source/model components can improve multilingual normalization, parsing evaluation, candidate ranking, topology QA, drift detection and bounded-error compression after authority and rights are established. They cannot supply the missing denominator, manufacture postal boundaries, grant reuse rights or identify an exact building.

Reconsider M2 only after Algérie Poste or another competent authority publishes a complete current immutable assignment denominator and exact real postal Polygon/MultiPolygon under compatible processing, derivation, redistribution and public-serving rights. Then verify normalization, loading, no match, multiple candidates, failure, invalid geometry, fit, translucent fill, clear outline, metadata, clear and re-search in the real DZ API/app. Retry after the pending-country sweep or 2026-12-03 unless an official release appears earlier.
