# 米国・メキシコ国境と中米のAGID判定

この詳細判定は、国境付近のピン、測位誤差を伴うピン、発行済みAGIDが示すセルに適用する。地形資料で確認した陸地と行政区域を重ね、住所に使える国候補を求める。各地点の結果には、判定に使用した資料の出典と版を含める。

| 地点・測位範囲 | AGIDの扱い |
| --- | --- |
| 一国の陸地の内側 | その国を候補にする。島では島としての判定も返す |
| 陸上の国境線、または複数国の陸地にかかる測位範囲 | 該当する国をすべて候補にし、どの国の住所か確認を求める |
| 河川・湖・海の水面に収まる地点 | 水域を返し、住所用の国候補は空欄にする |
| 岸線、資料の食い違い、詳細データの範囲をまたぐ測位誤差 | 陸地や国を自動確定せず、確認を求める |

## 地図資料の読み方

海面が確認された地点では、太平洋側の米墨国境終端とフォンセカ湾には東部北太平洋の海域コード `NEPC`、セント・ジョージズ・キー沖とボカス・デル・トロにはカリブ海の海域コード `CARB` を使う。住所用の国候補は空欄となる。

米墨国境には地上の標識で画された区間に加え、リオ・グランデ川やコロラド川を通る区間がある。行政境界が水路を通っていても、確認できた水面には配送先の国を付けない。行政境界には国際境界水委員会・米国部（USIBWC）が配布する地図用の線を使用する。地図上の線と各岸の判定精度は、測位端末が報告する誤差とは別に、元資料の縮尺・年代にも依存する。[国際境界水委員会による国境の説明](https://www.ibwc.gov/about-us/) · [同委員会GISの利用説明](https://www.ibwc.gov/gis-program/)

フォンセカ湾のエル・ティグレ島はホンジュラス、メアングエラ島とメアングエリータ島はエルサルバドルに属する。1992年の国際司法裁判所判決はこの3島の帰属と湾内水域の法的地位をそれぞれ扱っている。AGIDでは島の陸上にあるピンを判定し、湾の水面に島の国を広げない。[国際司法裁判所判決の要約](https://api.icj-cij.org/sites/default/files/case-related/75/6673.pdf)

モンテクリストではグアテマラ、ホンジュラス、エルサルバドルが接する。回帰テストには3つの行政区域が共有する地図上の頂点を使う。ベリーズ沖ではセント・ジョージズ・キーを個別に照合した。グアテマラの島に関する提出資料ではこの島が個別に挙げられているため、ここでの判定をほかのキー（小島）に一括適用しない。[トリフィニオ三国委員会](https://www.plantrifinio.int/donde-estamos/) · [グアテマラ側の2001年提出資料、第79項](https://belizereferendum.gov.bz/files/March%2030%202001%20Guatemala%27s%20presentation.pdf) · [ベリーズ憲法、第1附則](https://www.nationalassembly.gov.bz/wp-content/uploads/2023/09/Constitution-of-Belize-as-of-7-Nov.-2022.pdf)

## 検証例

| 地点（緯度・経度） | 地図に基づく期待結果 |
| --- | --- |
| ノガレスの陸上国境線（31.332735386836507, −110.94449996055343） | 陸地、米国・メキシコを候補にして確認を求める |
| ラレドの国境線が河道を通る地点（27.499946692521384, −99.50487203803706） | リオ・グランデ川の水面。住所用の国候補なし |
| モンテクリストの地図上の三国境（14.4204599, −89.3559607） | 陸地。グアテマラ、ホンジュラス、エルサルバドルの3候補 |
| フローレス島（16.930, −89.8913）と西の湖面（16.932, −89.897） | 島はグアテマラ、湖面は国候補なし |
| フォンセカ湾の3島の間（13.222, −87.672） | 海面。海域は東部北太平洋、住所用の国候補なし |
| ペニャス・ブランカス付近（11.216, −85.612） | 陸地。行政地図の線がずれるため国は要確認 |
| シクサオラ川（9.499, −82.614）、両岸（9.502, −82.614 と 9.495, −82.613） | 河道は国候補なし。前者の岸はコスタリカ、後者はパナマ |
| オメテペ島モヨガルパ（11.540, −85.700）と西の湖面（11.540, −85.705） | 町はニカラグア、湖面は国候補なし |
| コロン島とカレネロ島の間（9.341, −82.238） | 海面。海域はカリブ海、住所用の国候補なし |

回帰テストは境界データの線・頂点を再現できる桁数の座標を使う。現地での位置精度は元資料の測量・作成方法に依存する。

旧版（`ddf8eab`）と新版を同じ55地点で比較した。地表の種別、国候補の集合、確定・要確認の状態、陸地の場合は島・本土の区別という各地点の期待値がすべて一致したのは、旧版が3地点、新版が55地点だった。内訳は、一国の本土27地点・島8地点、水域12地点、陸上国境4地点、資料が食い違う4地点。国境や小島を選んだ回帰試験の件数で、地域全体の正答率を推定するものではない。

スチアテ川の同じピン（14.681, −92.1468）では、測位半径10 mなら全域が水面、60 mではメキシコの陸地が候補に入り、90 mではグアテマラの陸地にも達する。

## 再生成と検証

Python 3.11以上、GDAL、NumPy、Shapely 2を使用する。中米用のスクリプトにはFieldMaps International ADM0（USGS版、2025年7月29日）のGeoPackageと、GSHHG 2.3.7のシェープファイル配布ZIPが必要になる。[FieldMaps配布ZIP](https://data.fieldmaps.io/adm0/usgs/intl/adm0_polygons.gpkg.zip) · [GSHHG配布ページ](https://github.com/GenericMappingTools/gshhg-gmt/releases/tag/2.3.7)

米墨国境のビルダーは、USIBWCの国境線、米国地質調査所（USGS）NHDの水域、ESA WorldCover 2021 v200を取得し、保存した入力のSHA-256を固定している。WorldCoverの周囲3×3画素が陸または水として一致する箇所を使い、河川・海を確定するにはNHDの水域との一致も求める。このため河床の土地被覆と水域資料が食い違う場所は要確認になる。2021年の土地被覆やNHDは現在の水位の観測値を表さない。[米墨ビルダー](../scripts/build-us-mexico-review.py) · [USIBWC国境線](https://gisserver.ibwc.gov/agsserver/rest/services/USIBWCPublic/US_MexicoIB/FeatureServer/0) · [USGSの水域資料](https://www.usgs.gov/national-hydrography/national-hydrography-dataset)

中米北部ではWorldCover 2020 v100と2021 v200で対応する画素区画を読み、両年が陸地または恒常水面に一致する場所を抽出する。フローレス島とセント・ジョージズ・キーでは、検証点につながる陸地の内側を採用し、細い桟橋を除く。フォンセカ湾ではGSHHGとFieldMapsの島の輪郭を重ねる。WorldCoverのGeoTIFFを手元に用意した場合は `--worldcover-directory` を指定できる。[北部ビルダー](../scripts/build-northern-central-america-review.py)

中米南部ではWorldCover 2021 v200の `N06W084`・`N09W084`・`N09W087` タイル、JRC Global Surface Water v1.4の `occurrence_90W_10Nv1_4_2021.tif` と `occurrence_90W_20Nv1_4_2021.tif`、コスタリカCOD-ABの `cri_admin0` シェープファイル一式を同じディレクトリに置く。コスタリカの国境では2つの行政地図が一致した陸地に国候補を付ける。ボカス・デル・トロでは海域に対応するため、WorldCoverの水面と島・行政区域の輪郭を照合する。[南部ビルダー](../scripts/build-southern-central-america-review.py) · [HDX行政界データ](https://data.humdata.org/dataset/cod-ab-cri)

```sh
python3 scripts/build-us-mexico-review.py mx-inputs --download
python3 scripts/build-northern-central-america-review.py \
  --fieldmaps-gpkg adm0_polygons.gpkg --gshhg-archive gshhg-shp-2.3.7.zip
python3 scripts/build-southern-central-america-review.py southern-inputs \
  --fieldmaps-gpkg adm0_polygons.gpkg --gshhg-archive gshhg-shp-2.3.7.zip
npm run verify:agid-islands
```

検証座標、期待される国候補・陸水・島の判定、測位誤差や発行済みIDの検証条件は回帰テストに記録している。[地点別テスト](../src/lib/mesoamericanGeography.integration.test.ts) · [データのライセンスとクレジット](../DATA_LICENSES.md)
