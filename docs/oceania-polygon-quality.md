# オセアニアの島・礁湖・経度180度の判定

今回の詳細判定は13の国・地域にある16区域が対象。各区域の四隅、原典、版、帰属表示は `src/data/oceania*PolygonDetail.json` の各 `window` に記録した。広域地図を含む従来の地理判定には、この16区域の外でも対応している。

## 作戦と収録範囲

1. 島を海に、海や湖を陸地にしてしまう座標を旧版で調べる。住所に使われる島と、そのすぐ隣で住所を割り当ててはいけない水面・礁原を組にして選ぶ。
2. 公的な島名・水路・海岸資料から対象を確認し、複数時期の観測を照合する。確認できた陸地にだけ住所地域を付ける。浅い礁、潮位で状態が変わる場所、資料の間に隙間が残る場所では判定を保留する。
3. 経度180度をまたぐ区域は東西の原資料をつないでから輪郭を取り出す。ピン、GPS誤差円、AGIDセル、オフライン地図で同じ修正が働くことを検証する。

## 判定の根拠

タベウニ島では、東経側と西経側の衛星タイルを同じ経度軸に載せ、島と海峡それぞれの連続した面を復元する。幅を持つ測位判定もその座標系で照合する。180度線上の海峡が途中から旧地図の陸地に戻る帯を見つけたため、旧図と新図の両方が海を示す地点まで北端を広げた。北端の内外を8本の緯線・242個の経度で照合し、1,936地点すべてで水面になった。

環礁では、海岸線や生息域図、衛星観測、標高・水深を区域ごとに組み合わせる。浅く見える礁原が常に陸とは限らない。ポリネシアの3区域では粗い海底地形の周囲の画素も確認し、沖の深い水面は積極的に海と判定する。細い水路や浅い礁湖で干出の可能性が残る場合は住所地域を空欄にする。

島内の湖では、水域と島の陸地を別々のポリゴンにする。ナウル、サモア、ウォリス・フツナの3区域では、2年分のWorldCoverで水になり、かつJRCの1984～2021年の有効観測で水の出現率が80%以上となる湖内の連続部分を内水にした。「内水」はここでは島の中の水面を示し、塩分は分類に使わない。競合する湿地や湖岸は要確認になる。[ナウルのブアダ・ラグーン](https://www.fao.org/4/AC282E/AC282E02.htm) · [サモアのラノトオ湖](https://rsis.ramsar.org/ris/1412) · [ウベア島の湿地目録](https://brb.sprep.org/sites/default/files/2025-11/wallis-futuna-wetlands-directory.pdf)

島23地点・水面22地点・要確認17地点を選び、旧版と新版に同一座標を入力した。地表・所属候補・水域・島の識別などが期待値と一致した地点はピンで9/62から62/62、発行したAGIDのセルで8/62から62/62になった。小さな島の中心にピンがあっても、対応するセルが不確かな岸線を含む場合、セルに対しては確認を求める。この比較は選定地点に限る。

## 再生成とテスト

Python 3.11以降、GDAL/OGRのPythonバインディング、NumPy、Shapely 2を使う。島内湖の生成には `adm0_polygons.gpkg`（FieldMaps国際版、2025年7月29日）が必要。各生成器は原典の該当区域のダイジェストを照合する。配布条件とクレジットは[データ出典](../DATA_LICENSES.md)に掲載した。[FieldMaps国際版](https://fieldmaps.io/data/adm0/)

```sh
python3 scripts/build_oceania_australasia.py /tmp/agid-aunz --download
python3 scripts/build_oceania_melanesia.py
python3 scripts/build_oceania_micronesia.py /tmp/agid-micronesia --download
python3 scripts/build_oceania_polynesia.py /tmp/agid-polynesia --download
python3 scripts/build_oceania_island_lakes.py adm0_polygons.gpkg
npm ci
python3 scripts/test-americas-survey-polygons.py
python3 scripts/verify-americas-survey-polygons.py --region oceania
python3 scripts/verify-oceania-survey-runtime.py
npm run verify:agid-islands
```

形状検査は16区域の陸地146、水域32、所属146のポリゴンと465個の内周を対象にした。CIでは、ShapelyとAGIDで1,222地点・67の矩形検索を照合し、それぞれ3通りの等価な経度表記で同じ結果を確認する。さらに実際の高精細オフライン地図の確認142件が通過した。

## 次の拡張候補

対象外の島や海岸には、従来の広域地図による判定が残る。次はパプアニューギニアとソロモン諸島の居住島間の水路、トンガ・トケラウ・仏領ポリネシアの細い環礁島を優先候補とする。新しい区域ごとに集落の陸地、隣接水面、資料が一致しない岸、既存地図へ切り替わる外周を確認する。現地の満潮線や水深資料を取得できた浅瀬から、要確認の範囲を縮める。
