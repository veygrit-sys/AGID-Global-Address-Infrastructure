# 住所に応用できる情報工学技術 50

この文書は、AGID、AOID、住所写像論、住所翻訳理論、住所機械翻訳理論、Postal Forge、Secure Address QRに使える情報工学技術を整理した技術マップである。

目的は、住所を単なる文字列ではなく、検索可能、検証可能、翻訳可能、配送可能、秘匿可能、監査可能な情報インフラとして扱うことである。

## 優先順位

AGIDで実装優先度が高い順に見ると、次の順序がよい。

1. 検索・正規化: Trie、逆引きインデックス、N-gram、ファジー検索、全文検索
2. 住所機械翻訳: 形態素解析、NER、住所パーサー、音訳、目的別翻訳
3. 地理検証: ジオコーディング、リバースジオコーディング、GIS、空間インデックス
4. 郵便番号・配送区域生成: Voronoi、クラスタリング、経路最適化、H3/S2相当の格子
5. 台帳・履歴: リレーショナルDB、グラフDB、時系列DB、イベントソーシング、CRDT
6. プライバシー: 公開鍵暗号、トークン化、アクセス制御、監査ログ、ZK、DID/VC

AGIDでは、便利さよりも先に「raw住所を不用意に出さない」「検証不能な住所をVerified扱いしない」「住所IDと個人住所を混ぜない」を守る。

## 注意点

情報工学の技術を住所へ応用する時は、次の失敗を避ける。

- LLMの自然な翻訳をVerified扱いしない。
- 郵便番号が弱い国で郵便番号だけに依存しない。
- H3/S2/GeohashをAGIDの代替として無条件採用しない。
- 公開AGIDに個人住所、部屋番号、電話番号、受取人名を混ぜない。
- 検索便利化のためにraw住所をログや学習データへ流さない。
- 住所品質スコアを唯一の真実として扱わず、source、confidence、warningを併記する。
