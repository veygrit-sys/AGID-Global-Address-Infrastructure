# 世界の島の位置判定

AGIDはピンが実際に重なる陸地を調べ、その座標の国・地域候補を返す。島を複数の国が分けている場合はそれぞれの側を区別する。住所用の地域、地図上の主権国、領有権を主張する国、施政主体、受取人が指定した配送先は別の項目である。

| 入力例 | 地理判定の扱い |
| --- | --- |
| ボルネオ島 | ブルネイ、マレーシア、インドネシアをピンの位置で区別する |
| レユニオン | 地域はRE、主権国の欄はFRと表示する |
| 北方領土（択捉島・国後島・色丹島・歯舞群島）、竹島、尖閣諸島 | 日本政府の領土認識を採用し、該当する陸地の所属はJPのみとする |
| フォークランド諸島（マルビナス諸島） | 主張国の候補はAR・GB、施政主体はGB、確定した所属国の欄は空にする |
| 図にはあるが行政側の根拠がない岩礁 | 島の存在を返し、所属は未確定にする。周辺海域の国や一番近い国で補完しない |

日本の領土認識を指定する3地域には、国土交通省「行政区域データ」2026年版から作成した陸地1,766形状を使う。出典と日付の異なる全球図より優先する。外務省の見解は該当する島の公的根拠として表示する。領海や排他的経済水域から島の所属を決める処理は含まない。[国土交通省](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2026.html) · [北方領土](https://www.mofa.go.jp/mofaj/area/hoppo/hoppo.html) · [竹島](https://www.mofa.go.jp/mofaj/area/takeshima/) · [尖閣諸島](https://www.mofa.go.jp/mofaj/area/senkaku/)

沖ノ鳥島・南鳥島・西之島は、日本の通常の島として別に照合する。東京都の同じ2026年版資料から陸地18形状を収録した。沖ノ鳥島では北小島と東小島の護岸内に記録された中央の2形状だけを使用し、周囲の礁湖・護岸・独立した施設を島の陸地として扱わない。満潮時に露出する岩の寸法はこの資料からは決められない。西之島の形状は2026年1月1日時点の版に基づく。[国土交通省・沖ノ鳥島の概要](https://www.ktr.mlit.go.jp/keihin/keihin_index130.html) · [収録形状と出典](../src/data/japaneseRemoteIslands.json)

日本以外で個別に確認した44地域のうち、26地域で主張国を列挙し、16地域は資料や境界の状況から確認を要する。残る2地域は後年の協定・判決を採用した。群島全体に関する主張は個々の岩礁の主張・管理と区別する。この台帳と全球データのフラグを併用する。新たな係争、解決、地形の変化には原典の更新が必要になる。[地域ごとの根拠](../src/data/islandDisputePolicies.json)

## 標準の地図・CLIと高精細データ

| 収録層 | 数えたもの | 利用方法 |
| --- | --- | --- |
| 通常の島 | Natural Earthの物理的な島の地形部分4,058件と重なる行政形状4,084件。行政単位197、元の地域コード167種 | 同梱。陸地の穴、共有国境、180度経線の地図分割を考慮 |
| 小島・岩礁 | 地形2,798件。そのうち2,337件は一部または全域で行政資料と重なる | 同梱。重なりのない部分の所属は保留 |
| 高精細な海・湖の島 | GSHHGの地形ID181,607件と、FieldMapsの行政地形352,589部分を別々に索引化 | 追加のSQLiteデータを導入し、ローカル地図の手動ピンまたは専用コマンドから照会 |

同梱する通常層と小島層の行政資料に含まれる地域コードは、係争などの個別方針を適用する前の集計で168種。各行の数には別資料の重複や1島を分割した形状が含まれ、足し合わせても世界の島の数にはならない。[地域別CSV](island-region-coverage.csv) · [小島の検証](minor-island-coverage.md)

高精細版で各地形IDの代表点を元の行政資料と照合したところ、単一の行政地域と重なった代表点は72,657件、資料上の係争等のフラグがあるものは336件、行政コードが付かなかったものは108,585件、島内の湖・池に位置したものは29件だった。この検証は元データの代表点の照合であり、実際のピンはその位置で再照合する。別にFieldMapsの小規模な行政形状352,294件を検査し、同じ資料の中で孤立する137,665件を抽出した。うち136,872件には未係争の地域コードがある。AGIDが補助的な島判定に採用するのは、さらに独立した海岸線資料で海に囲まれることを確認した53,780形状で、このうち53,540件に未係争の地域コードがある（174コード）。GSHHGとFieldMapsの件数は重複し得る。海岸・潮間帯・新しい埋立地や登録外の岩礁まで、全球での判定完了を保証できる資料は用いていない。[高精細版の構築・照会・ライセンス](high-resolution-island-pack.md)

カナダと日本では、元の行政地図が欠ける島を両国の公的な陸地データでも照合する。島の全形状が公的な陸地内に収まったものが81件、そのほかに一部が重なったものが10,383件（カナダ9,290、日本1,093）ある。部分的な重なりは、その内側にピンを置いた場合だけ採用する。海、境界、確認が必要な係争地には広げない。これらは高精細版の181,607件の内数である。[照合方法と出典](high-resolution-island-pack.md)

元の行政資料でコードが付かなかった108,585代表点をAGIDで再照合したところ、所属を返したのは7,377点（同梱資料等6,364、島全体の照合による追加52、部分照合による追加961）だった。ほかに78点は係争として表示し、101,130点は所属を確定しなかった。これは元の未特定群だけを対象にした検証である。

## 飛び地と島を見分ける

同じ地点について、`territorialTopology.landform` で地形、`administration.kind` で周囲の国との関係を返す。陸地や境界を示す資料がある範囲で判定し、独立した行政区画が描かれているだけでは島に分類しない。

| ピンを置く場所 | 地形 | 行政上の扱い |
| --- | --- | --- |
| スペインのリビア（Llívia）市街地 | 大陸 | フランスに囲まれたスペインの飛び地 |
| バールレのオランダ領N1区画 | 大陸 | ベルギーの飛び地の内側にあるオランダの二重飛び地 |
| レソトの首都マセル | 大陸 | 南アフリカに囲まれた独立国 |
| ボルネオ島のバンガル | 島。島全体にブルネイ・インドネシア・マレーシアの領域がある | ピンはブルネイのテンブロン飛び地。マレーシア側のピンにはこのラベルを付けない |
| ティモール島のオエクシ市街地 | 島。ティモール島には東ティモールとインドネシアの領域がある | ピンは東ティモールの沿岸の飛び地 |
| マラウイ湖のリコマ島とチズムル島 | 湖の島 | モザンビークの水域に囲まれるマラウイの飛び地。島の間の湖面は対象外 |

`sharedIslandCountryCodes` は同じ地形を分け合う国を、`administration.neighboringCodes` は飛び地の周囲の国を表す。ピンや測位範囲で実際に候補となる国は `regionCandidates` に返す。GPSの誤差範囲が境界をまたぐ場合は確認が必要になる。飛び地台帳の対象外では行政分類を省略し、地形の証拠だけ不足する場合は判定を保留する。収録する飛び地・包領・包囲された独立国は26グループ、バールレの区画を個別に数えると53領域で、各グループに出典を記録した。[飛び地の対象地域・出典・再生成方法](territorial-exclave-sources.md)

標準版ではNatural EarthとGSHHGを照合し、個別に検証した地域ではESA WorldCover 2021 v200の10 m土地被覆も使用する。国境と海岸線を別々に扱うため、行政界が川や湖面に及ぶ場所では、その境界だけを根拠に陸地と表示しない。[地形判定の出典・収録範囲・再生成手順](landform-source-evidence.md) · [ESA WorldCover](https://esa-worldcover.org/en/data-access) · [GSHHG](https://github.com/GenericMappingTools/gshhg-gmt/releases/tag/2.3.7)

## 実行例

```sh
npm run agid -- geography --lat 37.24002 --lon 131.87016 --json
npm run agid -- geography --lat -51.794 --lon -58.61 --json
npm run agid -- geography --lat 2.5 --lon 113 --accuracy-meters 30 --json
npm run agid -- geography --lat 51.439542037 --lon 4.922922395 --accuracy-meters 500 --json
npm run agid -- geography --lat -12.066111111 --lon 34.730555556 --json
npm run verify:agid-islands
```

`island.countryCodes` は所属候補、`sovereignCodes` は根拠がある場合の主権国コード。係争地では `claimantCodes`、`administeringCode`、`claimScope` と出典を使う。`regionCandidates` は入力したピンや測位範囲に対する候補であり、`deliveryRegion` は常にnullを返す。AGIDだけの入力では元のピンを復元できないため、セル全体を覆う範囲を照合する。発行済みのIDは従来と同じセルに戻り、先頭の発行時コードは本人の住所国や領有権の証明には使わない。
