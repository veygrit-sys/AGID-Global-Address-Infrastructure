# 住所写像論 形式的基礎

本稿は、住所写像論を「住所らしいものをうまく扱う説明」から、写像、公理、定理、証明責任、計算量を持つ理論へ整理するための基礎章である。ここでの公理は、Leanに無証明で置く公理ではなく、論文上のモデル化前提である。実世界の住所データ完全性、全世界の候補生成完全性、商用APIより優れていること、ZK回路の暗号安全性は、この章では主張しない。

## 1. 基本対象

時刻または版を \(t\)、利用文脈を \(\chi\) とする。住所写像論は、少なくとも次の型を区別する。

| 記号 | 意味 |
| --- | --- |
| \(S_t\) | 表層住所表現。文字列、郵便番号、施設名、地名、コード、検索語など |
| \(X_t\) | 住所可能実体。建物、部屋、入口、道路、港、自然地物、文化地、仮想地点など |
| \(\Sigma_t\) | 出典束。行政、郵便、GIS、OSM、Overture、現場報告、履歴資料など |
| \(P_t\) | ポリシー。用途、公開範囲、品質しきい値、失効、監査、権限 |
| \(L_t\) | 住所履歴グラフ。改名、分割、統合、廃止、後継、再割当を表す |
| \(\Gamma_t\) | 候補生成写像 |
| \(D_{\chi,t}\) | 文脈依存の構造的非類似度またはコスト |
| \(Q_{\chi,t}\) | 品質・リスク・鮮度・出典信頼を含む内部ゲート値 |

AMTの中心写像は、単純な全域写像

\[
S_t \to X_t
\]

ではない。AMTの解決器は、文脈、出典、履歴、ポリシーに束縛された部分写像である。

\[
F_{\chi,t}: S_t \times \Sigma_t \times L_t \times P_t
\rightharpoonup
\mathrm{Res}_{\chi,t}(X_t)
\]

出力型は直和として定義する。

\[
\mathrm{Res}_{\chi,t}(X_t)
=
\mathrm{Resolved}(X_t)
\sqcup
\mathrm{Ambiguous}(\mathcal P_{\mathrm{fin}}(X_t))
\sqcup
\mathrm{Unresolved}(\mathrm{Reason})
\sqcup
\mathrm{Rejected}(\mathrm{Reason})
\]

したがって、住所写像論は「必ず1つ返す理論」ではなく、「返してよい場合と返してはいけない場合を区別する理論」である。

## 2. 厳密な公理

**公理 A1 型付き住所宇宙。**
各 \(t,\chi\) に対して、\(S_t\)、\(X_t\)、\(\Sigma_t\)、\(P_t\)、\(L_t\) を明示する。住所文字列、座標、郵便番号、AGID、AOID、ZK述語を同じ型として扱わない。

**公理 A2 有限な運用候補集合。**
固定された実行ポリシーの下で、候補生成写像

\[
\Gamma_t:S_t\to\mathcal P_{\mathrm{fin}}(X_t)
\]

は有限集合を返す。これは計算可能性のための前提であり、世界全体の候補完全性を意味しない。

**公理 A3 明示的な非発行状態。**
解決器は `resolved`、`ambiguous`、`unresolved`、`rejected` を返せる。PID候補を持てるのは `resolved` のみである。

**公理 A4 出典束縛証拠。**
証拠 \(e\in\Sigma_t\) は、出典、時点、管轄、ライセンス、カバレッジ、鮮度を持つ。未知または拒否された出典は、検証済み主張へ昇格しない。

**公理 A5 文脈宣言。**
各解決要求は文脈 \(\chi\) を持つ。配送、行政、緊急対応、本人確認、地図検索、匿名証明では最適な表現が異なり得る。

**公理 A6 PID発行ゲート。**
PIDを伴う出力は、候補所属、分離マージン、品質、鮮度、リスク、監査可能性の述語を満たす場合に限る。

**公理 A7 関係的履歴。**
住所履歴は単一値関数ではなく、関係またはグラフである。分割、統合、改名、廃止、後継を一次対象として扱う。

**公理 A8 タイブレークの明示。**
有限候補に複数の最小候補がある場合、決定的順序を宣言するか、曖昧として棄却する。

## 3. 存在定理

**定理 E1 条件付き解決存在定理。**
\(\Gamma_t(u)\) が有限で、候補 \(x\in\Gamma_t(u)\) が選択され、PID発行ゲート \(G_{\chi,t}(u,x,\Sigma_t,L_t,P_t)\) が真であり、タイブレークまたは正の分離マージンが宣言されているならば、AMT内部の `resolved(x)` は構成可能である。

**証明スケッチ。**
有限候補集合から、ゲートを満たす候補 \(x\) を取る。公理A6により発行条件が満たされ、公理A8により同点が処理される。よって直和型の構成子 \(\mathrm{Resolved}(x)\) を適用できる。

**注意。**
これはモデル内部の存在定理であり、\(x\) が実世界で真の配送先であることや、世界中の住所が候補集合に含まれることは証明しない。

**定理 E2 履歴グラフ表現存在定理。**
有限個の改名、分割、統合、廃止、後継イベントが受理済みであるなら、それらは有限有向グラフ \(L_t=(V_t,E_t)\) として表現できる。

**証明スケッチ。**
各住所状態を頂点、各履歴イベントをラベル付き辺として追加する。イベントが有限なら頂点・辺も有限である。

## 4. 一意性定理

**定理 U1 分離された最小候補の一意性。**
文脈 \(\chi\) において、候補 \(x^\ast\) が他のすべての候補 \(y\ne x^\ast\) に対して

\[
D_{\chi,t}(x^\ast,u)+m \le D_{\chi,t}(y,u)
\quad (m>0)
\]

を満たすならば、分離マージン付き最小候補は一意である。

**証明スケッチ。**
別の最小候補 \(z\ne x^\ast\) が存在すると仮定する。最小性により \(D(z,u)\le D(x^\ast,u)\) である。一方、分離条件から \(D(x^\ast,u)+m\le D(z,u)\)。\(m>0\) なので矛盾する。

**定理 U2 参照同値類PID不変性。**
住所表現 \(a,b\in S_t\) が同じ実体を参照し、

\[
\mathrm{ref}_t(a)=\mathrm{ref}_t(b)
\]

かつPIDが参照同値類から生成されるならば、

\[
\mathrm{pid}([a])=\mathrm{pid}([b])
\]

である。

**証明スケッチ。**
参照同値は同じ同値類を定める。PIDが同値類上の関数なら、同じ入力に対する関数値は等しい。

## 5. 不可能性定理

**定理 I1 無条件完全住所解決器不存在定理。**
観測写像 \(O_t:X_t\to S_t\) が非単射である、すなわち \(x_1\ne x_2\) かつ \(O_t(x_1)=O_t(x_2)\) が存在するなら、\(S_t\) のみを見る関数 \(R:S_t\to X_t\) は両方に対して完全には正しくなれない。

**証明。**
完全性を仮定すると

\[
R(O_t(x_1))=x_1,\quad R(O_t(x_2))=x_2
\]

である。ところが \(O_t(x_1)=O_t(x_2)\) なので左辺は同一であり、\(x_1=x_2\) が従う。これは \(x_1\ne x_2\) に反する。

**定理 I2 候補欠落不可回復定理。**
解決器が候補集合 \(\Gamma_t(u)\) の要素だけを返す候補健全性を持ち、真の対象 \(x^\ast\notin\Gamma_t(u)\) なら、解決器は \(\mathrm{Resolved}(x^\ast)\) を返せない。

**証明スケッチ。**
候補健全性より、返された対象は候補集合の要素である。\(x^\ast\) は候補集合に含まれないため矛盾する。

**定理 I3 射影損失不可回復定理。**
三次元・階層的対象 \(X^{3D}\) から地表投影 \(X^{2D}\) への射影

\[
\pi:X^{3D}\to X^{2D}
\]

が非単射なら、地表投影のみを見る解決器は階・部屋・入口・ロッカーなどの区別を完全には復元できない。

これは定理I1を \(\pi\) に適用したものである。

**定理 I4 文脈衝突による絶対住所不存在定理。**
二つの文脈 \(\chi_1,\chi_2\) の厳密最適出力集合が交わらないなら、

\[
\mathrm{Opt}_{\chi_1,t}(u)\cap \mathrm{Opt}_{\chi_2,t}(u)=\varnothing,
\]

両方に同時に最適な単一住所出力は存在しない。

## 6. 計算量解析

AMTの計算量は、候補生成、クラスタリング、スコアリング、履歴更新、発行ゲートに分ける。

| 処理 | 変数 | 時間 | 空間 | 備考 |
| --- | --- | --- | --- | --- |
| indexed candidate generation | \(n,q,k\) | \(O(q\log n+k)\) | \(O(n)\) | インデックスなしでは \(O(n)\) |
| pairwise structural clustering | \(k,d\) | \(O(k^2d)\) | \(O(k^2)\) | 大きい候補集合ではblockingが必要 |
| context scoring | \(k,f\) | \(O(kf)\) | \(O(k)\) | 特徴抽出が支配的になる場合がある |
| lineage update | \(e,h\) | \(O(e\log h)\) | \(O(e)\) | append-only ledgerやcontent addressと相性がよい |
| PID issuance gate | \(k,g\) | \(O(k+g)\) | \(O(1)\) | ZK証明生成は別論文の計算量 |

ここで、\(n\) は索引済み住所レコード数、\(q\) は検索キー数、\(k\) は候補数、\(d\) は構造距離成分数、\(f\) はスコア特徴数、\(e\) は履歴イベント数、\(h\) は履歴グラフ規模、\(g\) はゲート述語数である。

## 7. 証明体系

AMTの証明は、次の階層に分ける。

1. **Lean向き抽象定理**
   非単射、候補欠落、射影損失、関数では分割を表せない、参照同値類不変性など。

2. **論文上の構成定理**
   条件付き解決存在定理、履歴グラフ表現存在定理、監査リプレイ存在定理など。

3. **実装で検証する性質**
   no-raw-address gate、source validation、resolver conformance、PID issuance audit、address quality gateなど。

4. **経験的に検証する性質**
   世界規模候補生成リコール、多言語検索リコール、自然地理カバレッジ、商用API比較、配送到達性。

5. **別論文へ分離する性質**
   ZK回路の完全性、soundness、zero-knowledge性、Ethereum anchor、nullifier privacy、credential revocation。

## 8. 主張してよいこと・まだ弱いこと

**強く書ける。**

- AMTは住所解決を全域関数ではなく、文脈・証拠・履歴・ポリシーに束縛された部分写像として定義する。
- 非単射観測がある限り、無条件完全住所解決器は存在しない。
- 候補欠落は後段のスコアリングでは回復できない。
- 分割・統合履歴は単一値関数ではなく関係またはグラフを必要とする。
- PID発行は候補、品質、鮮度、リスク、監査ゲートに依存すべきである。

**弱めて書く。**

- 全世界の全住所・自然地物・建物内区画が候補生成に入るとはまだ言わない。
- 多言語検索が全言語・全方言・全旧地名で十分なリコールを持つとはまだ言わない。
- GIS hard error 0 は機械可読性と最小品質を示すが、世界地理完全性を示さない。
- ZK-ready envelope は完全なZK回路・暗号監査済みシステムではない。

## 9. AGID実装との対応

この章の機械可読カタログは `src/address/addressMorphismFormalSystem.ts` に置く。そこでは、公理、存在定理、一意性定理、不可能性定理、計算量境界をID付きで管理する。

対応する検証は `src/address/addressMorphismFormalSystem.test.ts` で行う。テストは、次を確認する。

- 公理と定理の重複IDがない。
- 各定理に証明スケッチと限界がある。
- 存在定理、一意性定理、不可能性定理が揃っている。
- 計算量がBig-O形式で記述されている。
- 世界完全性のような未証明主張を混入しない。

この分離により、論文本文は読みやすく、コード側は検証可能で、GitHub上では章ごとの差分管理がしやすくなる。
