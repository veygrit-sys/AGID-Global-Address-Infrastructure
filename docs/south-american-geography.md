# 南米の国境・島のAGID判定

南米12か国と仏領ギアナにまたがる22の範囲で、陸地・水面・島と住所に使う国や地域を個別に判定する。国境を通る川では、水面上のピンと対岸まで届くGPS測位を区別する。陸地ではピンが属し得る国・地域を返し、複数国を含む場合は住所国の確認を求める。各範囲の境界はデータの `bbox` に西・南・東・北の順で記録している。

## 国境と島の読み方

**三国境の陸地と水面。** サパレリ山ではアルゼンチンとチリの境界について山頂を条約上の端点とする原典がある。AGIDで使用する座標は出典地図の線と頂点に従う。イグアス側では、イグアス川がパラナ川に合流する水域を3国が囲み、記念碑は各国の岸に置かれている。合流点の水面にピンを置いた場合、住所国の候補は空になる。[アルゼンチンの条約批准法](https://www.argentina.gob.ar/normativa/nacional/norma-202355/texto) · [パラグアイ政府観光案内](https://visitparaguay.travel/places/hito-tres-fronteras)

**サンタ・ロサ。** ペルー政府は集落のある島をペルーに割り当てられたチネリア島の一部として扱う。コロンビア外務省はこの島を1929年の配分後に生じた地形と位置付け、帰属には両国の合意が必要だとしている。確認できた島の陸地と住所国の確定可否を個別に判定する。[ペルー政府の声明](https://www.gob.pe/institucion/pcm/noticias/1222890-comunicado) · [コロンビア外務省の声明](https://www.cancilleria.gov.co/node/30985)

**ラプラタ川。** 1973年条約第45条はマルティン・ガルシア島をアルゼンチンの管轄と定め、第46条は成長した島どうしが接した場合の境界を扱う。1988年の交換公文は島間の境界画定をラプラタ川管理委員会に委ね、根拠となる海図を指定している。岸線には土砂の堆積による変化があり、現在の水際だけでは条約上の線を再現できない。[条約第44～46条](https://ctmfm.org/documentos-basicos/tratado-del-rio-de-la-plata/) · [国連掲載の交換公文](https://www.un.org/Depts/los/LEGISLATIONANDTREATIES/PDFFILES/TREATIES/ARG-URY1988RP.PDF)

マルティン・ガルシア島とティモテオ・ドミンゲス島がつながる陸地では、島全体にアルゼンチンとウルグアイを表示する。ピンの住所国はアルゼンチン国土地理院（IGN）のマルティン・ガルシアを囲む線と、広域の行政区域の両方を照合して求める。[IGN国際境界レイヤーのメタデータ](https://www.ign.gob.ar/capas-sig/metadata/linea_de_limite_FA004.pdf)

**仏領ギアナ。** サリュ諸島の島や仏領ギアナの川岸には住所地域コード `GF` を使用する。サリュ諸島で主権国を表すコードはフランスの `FR`。島の間にある大西洋の水面に住所国を付けない。[フランス国立宇宙研究センターの島別解説](https://cnes.fr/geoimage/iles-salut) · [フランス国立統計経済研究所の行政地理台帳](https://www.insee.fr/fr/metadonnees/geographie/departement/973-guyane)

**フエゴ島。** サン・セバスティアンの陸上国境の両側は同じフエゴ島にある。島全体に含まれる国を示す `sharedIslandCountryCodes` はアルゼンチンとチリとなる。住所国の候補 `regionCandidates` は個々のピンまたは測位範囲と国境線の位置関係から求める。[アルゼンチンの国境施設案内](https://www.argentina.gob.ar/node/464616) · [アルゼンチン外務省の国境条約記録](https://tratados.cancilleria.gob.ar/tratado_ficha.php?id=kqGjng%3D%3D)

フォークランド諸島（マルビナス諸島）は既存の係争地登録を使用する。英国の施政と、アルゼンチン・英国の主権主張を別の項目に保ち、今回の回帰テストでも確認した。ガイアナで収録した範囲は東部コランタイン川の渡船場付近であり、対ベネズエラ国境をめぐるエセキボの係争地域はこの22範囲の外にある。[AGIDの係争地登録](../src/data/islandDisputePolicies.json) · [国連のフォークランド諸島（マルビナス諸島）資料](https://digitallibrary.un.org/record/4111019) · [国際司法裁判所のガイアナ対ベネズエラ事件](https://www.icj-cij.org/case/171)

## 検証例

対象範囲から選んだ69地点で、陸水、候補国の集合、確定・要確認の状態、陸地の場合は本土・島の区分を照合した。全項目が期待値に一致した地点は旧版（`9686a94`）で3地点、更新後で69地点だった。内訳は本土25、島15、水面17、要確認12地点。要確認のうち6地点は陸地を確認でき、残り6地点は陸水も保留する。この比較は選んだ地点に限られる。

| 地点（緯度、経度） | 期待する判定 |
| --- | --- |
| レティシアとタバチンガの市街地（−4.22250, −69.94000） | 陸地。約15 mずれた2つの行政地図の線の間にある。ピンと半径5 mの範囲には確定国がなく、半径12 mではブラジル・コロンビア双方の確認済み陸地に届く |
| サンタ・ロサの集落（−4.22260, −69.95922） | 島の陸地。住所国は要確認。旧版で発行済みの `CO` 接頭辞の12文字・16文字IDも同じセルに復号できる |
| サパレリの地図上の頂点（−22.813797, −67.1807） | 陸地。アルゼンチン・ボリビア・チリの3候補 |
| イグアス川・パラナ川の合流点（−25.592, −54.593） | 半径160 mは水面。範囲を広げると、250 mでブラジル岸、285 mでアルゼンチン岸、300 mでパラグアイ岸にも届く。岸に届いた場合は住所国を要確認とする |
| マルティン・ガルシアの飛行場（−34.18222, −58.24694）、ティモテオ・ドミンゲス（−34.1796294, −58.2557995） | 前者はアルゼンチン、後者はウルグアイ。同じ連続した陸地でも地図の境界線が異なる地点（−34.1759589, −58.2536087）は住所国を保留 |
| オヤポック川の国際橋（3.85633737, −51.82537976） | 橋と直下の水面が同じ緯度・経度に重なるため陸水・住所国を要確認とする |
| コランタイン川の渡船場付近（5.78059, −57.17125 と 5.74972, −57.135） | 西岸はガイアナ、東岸はスリナム |
| サン・ミゲル川（0.249875, −76.869125） | 川面。住所国候補なし |
| マカラ川の橋付近（−4.392694, −79.964306） | 両岸を確認できる資料の間に残る地点。陸水・住所国は要確認 |
| 太陽の島のユマニ（−16.032, −69.153）、東の湖面（−16.035, −69.14108） | 島の陸地はボリビア。湖面には住所国候補なし |
| イタバカ海峡（−0.49166, −90.2903）、両側の島（−0.494, −90.284 と −0.476, −90.274） | 海峡は南東太平洋。サンタ・クルス島、バルトラ島の陸地はエクアドル |
| フェルナンド・デ・ノローニャの滑走路（−3.854722222, −32.428333333）と沖合（−3.839, −32.432） | 滑走路はブラジルの島の陸地、沖合は南大西洋 |

## 検証と再生成

判定に使った資料の版、クレジット、根拠URLは各データの `version`、`attribution`、`evidenceUrls` に記録する。WorldCoverの2020年版・2021年版は観測当時の土地被覆を示すため、河床の移動や直近の水位変化は別に確認する必要がある。[ESAのデータ説明](https://esa-worldcover.org/en/data-access) · [AGIDのデータライセンス](../DATA_LICENSES.md)

北部ではWorldCoverの2年分の画素を比較し、各年の周囲3×3画素で陸水が一貫する部分を取り出す。国が分かっている河岸の陸地をFieldMapsの範囲と突き合わせる。レティシアとタバチンガでは、ブラジル地理統計院（IBGE）のタバチンガ市域も重ね、線が一致しない帯では陸地と判定できても住所国を保留する。オヤポック川の国際橋はフランス国立地理・森林情報研究所（IGN）の測量線を使い、橋面と水面が重なる帯を要確認にする。[フランスIGNのBD TOPO](https://geoservices.ign.fr/bdtopo) · [北部ビルダー](../scripts/build-south-america-north.py) · [IBGEの行政境界](https://www.ibge.gov.br/geociencias/organizacao-do-territorio/malhas-territoriais/15774-malhas.html)

アンデスの陸水にはWorldCover 2020/2021と欧州委員会JRCの過去の水域出現頻度を重ねる。川の両岸にある検証点が別々の陸地として残る範囲に絞り、河川・湖の水面には両年の土地被覆とJRC出現頻度75%以上の一致を求める。マカラ川の橋付近では、両岸のみを確認できる。ガラパゴスの海面は、両年の水面画素のうち行政資料とGSHHGの島の輪郭の双方から外れる地点を採用する。[アンデス・ガラパゴスのビルダー](../scripts/build-south-america-andes.py) · [イタバカ海峡のガラパゴス国立公園資料](https://www.galapagos.gob.ec/wp-content/uploads/downloads/2019/11/000081.pdf)

南部では両年のWorldCoverから乾いた陸地と水面を抽出し、イグアス／パラナの三国境では各国側の記念碑の陸地を別々に検証する。サン・セバスティアンではIGNの国境線で島の陸地を分割する。リベラ／サンタナ・ド・リブラメントではブラジルの市域図と国境図を照合する。フロリアノポリスではサンタ・カタリーナ島の陸地を島西側の本土と区別する。[南部ビルダー](../scripts/build-south-america-south.py)

離島では植生・市街地の陸地と海面を照合した。フェルナンド・デ・ノローニャでは両年のWorldCoverが公式空港の位置まで一様に水域と分類していた。検証した範囲にはGSHHGの島輪郭、行政区域、Copernicus GLO-30の地表面高とJRCの水域記録を使用する。ロビンソン・クルーソー島とグラン・ロケ島ではWorldCoverの2年分の分類、行政区域、空港・集落の場所を確認した。[離島ビルダー](../scripts/build-south-america-offshore.py) · [フェルナンド・デ・ノローニャの航空情報](https://aisweb.decea.mil.br/?codigo=SBFN&i=aerodromos) · [チリ民間航空総局の空港情報](https://aipchile.dgac.gob.cl/designador/SCIR) · [ロス・ロケスのラムサール条約登録資料](https://rsis.ramsar.org/RISapp/files/RISrep/VE856RIS.pdf)

Python 3.11以上、GDAL、NumPy、Shapely 2を用いる。FieldMapsの2025年7月29日国際版GeoPackageと、GSHHG 2.3.7のフル解像度シェープファイルZIPを用意する。各ビルダーは対象のデータファイルまたは使用する画素区画のSHA-256を照合する。オンライン実行ではラスターの必要範囲をリモートから読み、南部のビルダーは取得済みの入力を指定ディレクトリに保存する。[FieldMaps国際版ZIP](https://data.fieldmaps.io/adm0/usgs/intl/adm0_polygons.gpkg.zip) · [GSHHG 2.3.7の配布物](https://github.com/GenericMappingTools/gshhg-gmt/releases/tag/2.3.7)

```sh
python3 scripts/build-south-america-north.py --fieldmaps-gpkg adm0_polygons.gpkg
python3 scripts/build-south-america-andes.py --fieldmaps-gpkg adm0_polygons.gpkg --gshhg-archive gshhg-shp-2.3.7.zip
python3 scripts/build-south-america-south.py south-inputs --fieldmaps-gpkg adm0_polygons.gpkg --gshhg-archive gshhg-shp-2.3.7.zip
python3 scripts/build-south-america-offshore.py --fieldmaps-gpkg adm0_polygons.gpkg --gshhg-archive gshhg-shp-2.3.7.zip
npm run verify:agid-islands
```
