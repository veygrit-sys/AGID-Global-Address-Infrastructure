# AGID Operations Docs

Operational documents live here: release gates, repository hygiene, security
operations, load-test plans, deployment policies, and incident-ready processes.

This directory is for documents that explain how AGID is operated, reviewed,
released, or kept safe. Product concepts belong in `docs/product/`; research
and theory belong in `docs/research/`; protocol and API specifications belong
in `docs/specs/`.
