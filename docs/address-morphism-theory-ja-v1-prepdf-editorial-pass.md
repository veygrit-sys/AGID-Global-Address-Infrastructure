# 6. 章末結論の統一

PDF版では、全章に長い結論を置く必要はない。代わりに、部の節目だけを強くする。

| 章 | 結論の役割 |
| --- | --- |
| 第6章 | 第1部の結論。問題設定と不可能性定理を閉じる |
| 第12章 | 第2部の結論。AMT写像連鎖とPID発行を閉じる |

その他の章は、最後の段落を「本章では...を示した」程度に短くする。

1. 章番号付きの定義・補題・命題・定理へ整番する。
2. 付録Gの図式を本文へ移植するか、PDF版では図として組む。
3. 第18章と第19章のZKP/AGID/AOID境界説明を少し圧縮する。
4. 第16章を自然地理の主章として強め、第1章・第3章・第8章の例は軽くする。
5. 参考文献・データソース一覧を別途追加する。
6. LuaLaTeXまたはPandoc向けのPDF変換ファイルを作る。
