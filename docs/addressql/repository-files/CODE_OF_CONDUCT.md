# AddressQL Code Of Conduct

AddressQL is a technical project for safer address query infrastructure.  The
project welcomes contributors from database, GIS, logistics, privacy,
standards, and open-source communities.

## Expected Behavior

- Be respectful and precise.
- Treat privacy and safety concerns seriously.
- Discuss technical disagreements with evidence and test cases.
- Avoid political or identity assumptions when discussing country, region, or
  postal metadata.
- Keep examples synthetic unless a maintainer explicitly approves open data with
  a compatible license.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private address, recipient, witness, key, credential, or proof
  secret material.
- Using issues or pull requests to identify or track a real person.
- Presenting AddressQL outputs as legal proof of residence, identity,
  sovereignty, or delivery guarantee.

## Enforcement

Maintainers may edit, hide, or remove comments and contributions that violate
this code.  Repeated or severe violations may result in temporary or permanent
loss of participation privileges.
