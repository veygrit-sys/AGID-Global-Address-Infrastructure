# 住所写像論 日本語版 v1 付録A/B 追加・編集差分案

対象: 付録A「中核記法」および付録B「定義・命題・補題・定理・系一覧」

目的: 付録A/Bを、本文全体の索引として使える形に補強する。特に、付録Bが「すべて証明済み」と誤読されないよう、検証状態を明示する。

## 1. 付録Aの冒頭に加える文

挿入位置: 付録Aの冒頭直後。

> 本付録の記法は、住所写像論の中核概念を整理するためのものである。各記法は、本文中の定義、実装上の状態、検証方法と対応する。ただし、記法が存在することは、その記法で表された性質が無条件に成立することを意味しない。特に、候補生成、クラスタ、品質、履歴、PID発行は、出典、文脈、鮮度、粒度、リスクに依存する。

## 8. 付録Bに入れるべき注意書き

挿入位置: 付録Bの末尾。

> 本付録の一覧は、AMTの主張を体系化するための索引である。Leanで形式化された主張は、抽象化された前提の下で成立する。GIS検証、郵便ソース検証、実装テストで支持された主張は、対象データセット、対象国、対象地物、検証範囲に依存する。したがって、未検証の地域、未登録の出典、境界が不明な自然地理、変動する社会的住所については、AMTは完全解決を断定せず、ambiguous, unresolved, conditional, rejectedのいずれかを返す。

## 9. 応用層として分離する項目

次の項目は重要だが、住所写像論本体の定理としてではなく、応用論文または実装論文で扱う。

| 項目 | 分離理由 |
| --- | --- |
| AGID | 公開地理参照、通信、登録、監査、SDKの実装責務を持つ。 |
| AOID | 私的操作住所、所有、委譲、QR、配送権限などの実装責務を持つ。 |
| ZK Address Proof | 暗号的soundness、zero-knowledge、回路監査が必要であり、AMT本体とは責任範囲が異なる。 |
| Credential issuer trust | 発行者信頼、失効、鮮度、用途スコープは別の信頼モデルである。 |
| Polkadot連携 | アンカリング、ガバナンス、オンチェーン登録はプロトコル設計の問題である。 |
| MCP対応 | 外部Agentや買い物Agentとの入出力契約はアプリケーション層である。 |

## 10. 付録A/Bの最終方針

付録Aは「記法表」として残す。付録Bは「主張カタログ」ではなく、「検証状態付き主張カタログ」とする。これにより、住所写像論は、証明済みの抽象理論、実装検証、GIS検証、概念仮説、応用層を混同せずに提示できる。
