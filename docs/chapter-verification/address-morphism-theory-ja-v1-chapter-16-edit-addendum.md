# 住所写像論 日本語版 v1 第16章 追加・編集差分案

対象: 第16章「自然地理・文化地理・垂直参照」

本差分案は、第16章をより数学的に正確で、実装と検証結果に接続しやすい形へ修正するための本文案である。中心方針は、自然・文化地物を住所的参照対象として広げつつ、郵便配送可能性、到達点、地図ラベル、法的境界、垂直区画を混同しないことである。

## 1. 章冒頭に追加する要約

第16章の冒頭に、次を追加するとよい。

> 本章では、住所写像論を建物住所や郵便住所に限定せず、自然地理、文化地理、道路網、垂直区画を含む参照体系へ拡張する。川、湖、滝、島、山、砂漠、湿地、氷原、遺跡、世界遺産、道路、橋、公園などは、郵便物の宛先ではない場合でも、検索、案内、災害支援、保全管理、観光、研究、行政参照において住所的な意味を持つ。

続けて、次を入れる。

> ただし、住所的参照対象であることは、配送可能点であることを意味しない。湖そのものに荷物を届けるのではなく、湖畔の管理事務所、港、浜、駐車場などへ届ける。山そのものに到達するのではなく、登山口、山小屋、駐車場、管理区域へ到達する。したがってAMTでは、参照対象、アクセス点、配送可能点を分離して扱う。

## 2. 用語を整理する

第16章の早い段階で、次の用語を定義すると章全体が安定する。

### 定義16.1 参照住所

> 参照住所とは、実体を検索、表示、識別、共有、記録するための住所的表現である。自然地理、文化地理、道路、橋、海域、山地、湖、遺跡などを含む。

### 定義16.2 アクセス住所

> アクセス住所とは、参照対象へ到達するための入口、駐車場、港、登山口、橋、受付、管理事務所、案内所などを表す住所的表現である。

### 定義16.3 配送住所

> 配送住所とは、郵便物、荷物、サービス、権限、鍵、通知などを実際に届けることができる住所的表現である。郵便受け、宅配ロッカー、受付、部屋、区画、店舗、事務所などを含む。

### 定義16.4 地物型

> 地物型とは、住所的参照対象の幾何・意味粒度を表す型である。

```text
FeatureType = {
  point,
  line,
  area,
  volume,
  network,
  cultural_boundary
}
```

各実体には、時刻と出典に応じて地物型を付与する。

```text
kind_t : X_t -> FeatureType
```

地物の幾何は、出典に依存する部分関数として扱う。

```text
geom_t : X_t -> Optional(Geometry_t)
source_t : X_t -> SourceSet_t
```

ここで `Optional` とするのは、名前は存在しても形状や境界が十分に確定していない地物があるためである。

## 3. 参照対象、アクセス点、配送点の表を追加する

第16.1節または第16.8節に、次の表を入れると読者に伝わりやすい。

| 対象 | 参照住所 | アクセス住所 | 配送住所 |
|---|---|---|---|
| 湖 | 湖名、湖面、湖岸、流入口、流出口 | 港、浜、駐車場、展望台 | 管理事務所、施設受付 |
| 山 | 山名、山体、峰、稜線、登山道 | 登山口、駐車場、山小屋 | 山小屋、管理所、救助拠点 |
| 川 | 河川名、支流、河口、区間 | 橋、堤防入口、船着場 | 河川事務所、観測所 |
| 島 | 島名、島全体、集落、港、灯台 | 港、空港、船着場 | 住居、店舗、役場、ロッカー |
| 遺跡 | 遺跡名、構成資産、文化財範囲 | 入場口、案内所、駐車場 | 管理事務所、受付 |
| 世界遺産 | 登録範囲、緩衝地帯、構成資産 | 入口、案内所、交通結節点 | 管理者住所、受付 |

本文案:

> この表が示すように、同じ名称であっても、検索で必要な対象、現地へ向かう対象、配送で必要な対象は異なる。AMTはこれらを同一視せず、関係として接続する。

## 4. 16.2を地物型の節として強化する

第16.2節の末尾に、次を追加する。

> 地図ラベルは、多くの場合、実体そのものではなく表示上の観測点である。湖名ラベルは湖全体ではなく、山名ラベルは山体全体ではなく、世界遺産ラベルは登録範囲や緩衝地帯そのものではない。したがってAMTでは、ラベル点、幾何形状、法的境界、アクセス点を別々の対象として扱う。

命題として次を置く。

### 命題16.1 地物型明示命題

> 住所的参照対象が点、線、面、体積、ネットワーク、文化境界のいずれであるかを明示しない場合、同じ名称が異なる幾何粒度へ解釈され得る。

証明の考え方:

> 例えば「川」は、河川全体、特定区間、支流、河口、橋付近、観測所付近のいずれも指し得る。地物型を明示しない場合、同じ名称が複数の候補へ対応する。したがって、名称だけでは一意の幾何対象を決定できない。

## 5. 16.3の水系記述を補強する

第16.3節に、次の分類を追加する。

```text
WaterFeature = {
  sea,
  bay,
  coast,
  river,
  stream,
  waterfall,
  lake,
  pond,
  wetland,
  salt_lake,
  inlet,
  outlet,
  harbour,
  beach
}
```

本文案:

> 水系地物は、単なるwaterとして扱うと情報が失われる。河川は線またはネットワークであり、湖は面であり、滝は点状の観測対象でありながら、遊歩道、展望台、駐車場、危険区域、管理主体を伴う。したがってAMTでは、水系地物を地物型、流域、近傍施設、アクセス点、季節変化、危険属性、出典とともに扱う。

注意書きとして次を入れる。

> 地図上の水域名は、必ずしも安全な到達点を意味しない。洪水、干満、凍結、季節湖、乾季の消失、私有地、保護区域、危険区域は、配送や案内の文脈で別属性として扱う必要がある。

## 6. 16.4の疎自然地理を補強する

第16.4節に、次を追加する。

```text
SparseNaturalFeature = {
  mountain,
  valley,
  cave,
  desert,
  grassland,
  forest,
  wetland,
  salt_flat,
  ice_field,
  glacier,
  wilderness,
  reef,
  spring
}
```

本文案:

> 山地、砂漠、塩原、湿地、氷原、氷河、草原、森林、洞窟、谷などでは、郵便住所が弱い、または存在しない場合がある。このとき、AMTは住所解決を放棄するのではなく、自然地名、座標、地物型、標高、水系、土地被覆、保護区、研究機関データ、OSM、国際地名集などを組み合わせて、参照住所を構成する。

ただし、次の限定を必ず入れる。

> 自然地理の境界は、地図ソース、研究データ、行政境界、保護区境界により異なることがある。したがって、AMTは境界を絶対値として扱わず、出典に拘束された幾何 `source-scoped geometry` として扱う。

## 7. 16.5の島名記述を修正する

第16.5節では、「世界全ての島名を認識できる」という印象を避け、次のように書き換える。

> AMTは、島、小島、諸島、環礁、岩礁、cay、key、reefなどを住所的参照対象として扱う。ただし、世界全ての島名を無条件に認識することは、現時点では主張しない。島名の解決は、公式地名集、国際地名集、海図、OSM、自然地理データ、行政データ、現地名、旧名、翻訳名を束ねる出典拘束的な候補生成問題である。

反例を本文に入れる。

> 同じ島名が複数国に存在する場合、現地名と英語名が一致しない場合、無人島や岩礁が地図ソースごとに異なる場合、係争地で行政管轄が一致しない場合、名称だけで一意の島を決定することはできない。

命題として次を置く。

### 命題16.2 出典拘束的島名解決命題

> 島名の完全解決は、参照する出典集合、言語集合、更新時刻、地物型、領域範囲に依存する。これらを固定しない限り、「全島名の完全認識」は検証可能な主張にならない。

Lean対応として、次を脚注または本文に置く。

```text
missing_entity_refutes_candidate_completeness
```

意味:

> 候補生成器がある島を候補に含めないなら、その島について候補完全性は成立しない。

  cultural_property,

注意書き:

## 9. 16.7の垂直参照を定理として書き直す

第16.7節では、2D座標の不十分性を次の定理として置く。

### 定理16.3 垂直射影衝突定理

> `X3D_t` を垂直参照を含む実体空間、`Ground2D_t` を地表2D参照空間とする。射影
>
> `P2D : X3D_t -> Ground2D_t`
>
> が非単射であり、`P2D(x1) = P2D(x2)` かつ `x1 != x2` を満たす二つの実体が存在するとする。このとき、`Ground2D_t` だけを入力とする解決器は、`x1` と `x2` を同時に完全解決できない。

証明案:

> そのような解決器 `r : Ground2D_t -> X3D_t` が存在し、`r(P2D(x1)) = x1` かつ `r(P2D(x2)) = x2` を満たすと仮定する。ところが `P2D(x1) = P2D(x2)` であるため、左辺は同じ値になる。したがって `x1 = x2` となる。しかし仮定では `x1 != x2` である。矛盾。

Lean対応:

```text
projection_collision_prevents_vertical_resolution
```

本文案:

> この定理は、2D座標を否定するものではない。2D座標は強力な参照である。しかし、同じ地表位置に複数の垂直実体が存在する場合、階、部屋、入口、地下、屋上、ロッカー、駐車区画、内部経路などを追加しなければ、完全な住所解決はできない。

## 10. 16.8をアクセス関係として整理する

第16.8節を、次の関係で整理する。

```text
Access_t subset X_t x X_t
Delivery_t subset X_t
Reference_t subset X_t
```

意味:

```text
Access_t(x, a)
```

は、参照対象 `x` へ到達するためのアクセス点が `a` であることを表す。

本文案:

> AMTでは、対象実体 `x` と到達点 `a` を同一視しない。湖 `x` のアクセス点は港、浜、駐車場、管理事務所 `a` であり得る。山 `x` のアクセス点は登山口、山小屋、駐車場 `a` であり得る。世界遺産 `x` のアクセス点は入口、案内所、受付、管理事務所 `a` であり得る。

命題として次を置く。

### 命題16.4 アクセス関係分離命題

> 参照対象であることは、到達点であることを含意しない。配送、避難支援、観光案内、保全管理では、参照対象 `x` とアクセス点 `a` の関係 `Access_t(x, a)` を明示する必要がある。

## 11. 出典、ライセンス、鮮度の節を追加する

第16章の末尾に、短い節として次を追加するとよい。

### 16.x 出典拘束性と更新

> 自然地理・文化地理・垂直参照は、郵便住所以上に出典差が大きい。OSM、公式地名集、海図、国土地理データ、保護区データ、NASAや宇宙機関の地球観測データ、世界遺産データ、自治体データ、現地施設データは、それぞれ更新頻度、ライセンス、幾何粒度、名称体系が異なる。したがってAMTでは、地物を採用する際に、少なくとも出典、更新時刻、ライセンス、地物型、品質、未解決状態を記録する。

安全な記法:

```text
evidence_t(x) = {
  source_ids,
  observed_at,
  license_class,
  feature_type,
  geometry_granularity,
  quality_score,
  unresolved_reason
}
```

注意:

> この記録は、地物が真であることの絶対証明ではない。どの出典に基づき、どの時点で、どの粒度で、どの程度の品質で採用されたかを監査可能にするためのものである。

## 12. 章末まとめ案

第16章の末尾を次のように締めるとよい。

> 本章では、住所写像論を自然地理、文化地理、道路網、垂直区画へ拡張した。川、湖、滝、島、山、砂漠、湿地、氷原、遺跡、世界遺産、道路、橋、公園などは、郵便住所ではない場合でも、住所的参照対象となり得る。ただし、それらは常に配送可能点ではない。AMTは、地図ラベル、実体、幾何、法的境界、アクセス点、配送点、出典、品質、未解決状態を分離することで、自然・文化地物を安全に住所体系へ統合する。

続けて、第17章への橋渡しを入れる。

> 次章では、このような参照対象を実際に候補生成、クラスタリング、評価、履歴更新、PID発行へ接続するための実装モデルを扱う。第16章の分離原則は、自然住所、地図地物住所、垂直参照、到達点補正、品質スコアの基礎となる。

## 13. 第16章で避けるべき表現

次の表現は避ける。

| 避ける表現 | 理由 | 修正案 |
|---|---|---|
| 世界全ての島名を認識できる | coverage証明がない | 出典集合内で島名候補を生成できる |
| 地図から取れば住所表示できる | ラベル点、境界、ライセンス、鮮度が不足 | 地図出典を明示して参照住所を生成できる |
| 湖や山に配送できる | 参照対象と配送点が異なる | 湖や山に対応するアクセス点または管理点へ配送できる |
| 2D座標で十分 | 垂直衝突がある | 2D座標は基礎参照だが垂直情報が必要な場合がある |
| 世界遺産ラベルが境界を示す | 法的境界とラベル点が異なる | 世界遺産の構成資産、緩衝地帯、入口を分離する |

## 14. 最終的な編集方針

第16章は、次の五つを柱にするとプロの論文として強くなる。

1. 自然・文化地物を住所的参照対象として認める。
2. 参照住所、アクセス住所、配送住所を分離する。
3. 点、線、面、体積、ネットワーク、文化境界を明示する。
4. 2D射影だけでは垂直参照を失うことを定理化する。
5. 世界完全coverageではなく、出典拘束的な候補生成として記述する。

この修正により、第16章は、自然地理表示の機能説明ではなく、住所写像論の「対象空間拡張」の章として位置づけられる。
