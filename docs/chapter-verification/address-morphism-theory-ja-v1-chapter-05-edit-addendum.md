# 住所写像論 日本語版 v1 第5章 追加・編集差分案

作成日: 2026-06-06

対象: `docs/address-morphism-theory-ja-v1-master.md` 第5章

目的: 第5章「形式的準備」を、後続の定理章と実装検証に耐える記法章へ整えるための差し込み文、置換文、数理モデル、記法表をまとめる。

## 1. 編集方針

第5章は、論文全体の記号の土台である。ここでは、強い新規主張を増やすよりも、各章で使う概念を明確に分けることを優先する。

本文冒頭に、次の方針を追加するとよい。

> 本章の目的は、住所写像論で用いる基本対象の型を定めることである。特に、表面表現、観測、実体、候補、クラスタ、参照クラス、解決結果、PIDを混同しないことが重要である。後続章の定理は、これらの区別を前提として成り立つ。

## 2. 第5章冒頭に追加する記法表

5.1の前または5.1直後に、次の表を追加するとよい。

| 記号 | 名称 | 意味 |
| --- | --- | --- |
| \(t\) | 時刻 | 住所体系、履歴、出典、配送制約が評価される時点 |
| \(W_t\) | 世界状態 | AMTが時刻 \(t\) に参照可能な住所意味論的状態 |
| \(X_t^{world}\) | 理論上の実体集合 | 時刻 \(t\) に存在し得る住所可能実体の理論的集合 |
| \(X_t^{known}\) | 既知実体集合 | AMTが登録済みデータや推定器で扱える実体集合 |
| \(S_t\) | 表面表現集合 | 住所文字列、郵便番号、座標、コード、地物名、旧住所など |
| \(Y_t\) | 観測空間 | 正規化、トークン、言語、地理候補、郵便照合、出典など |
| \(C\) | 文脈集合 | 配送、行政、緊急対応、登記、観光、災害支援など |
| \(c\) | 文脈 | 特定の解決目的 |
| \(\alpha_t\) | 解析写像 | 表面表現を観測へ変換する写像 |
| \(\Gamma_{c,t}\) | 候補生成写像 | 観測から候補実体集合を生成する写像 |
| \(D_{c,t}\) | 構造的非類似度 | 候補同士の差を測る非距離的な量 |
| \(\Pi_{\delta,c,t}\) | クラスタ分割 | 候補集合を参照候補クラスタへ分ける操作 |
| \(E_{c,t}\) | 評価関数 | クラスタの証拠、品質、リスク、鮮度を評価する関数 |
| \(\mathcal{R}(A)\) | 解決結果型 | resolved, ambiguous, unresolved, rejected を含む型 |
| \(G_H\) | 履歴グラフ | 改名、分割、統合、失効、再発行などを表す有向グラフ |
| PID | 永続識別子 | ゲートを通過した参照クラスまたは発行対象に付与される識別子 |

狙い:

第5章で曖昧な言葉を残さない。特に、`Address`, `Observation`, `Entity`, `Candidate`, `Cluster`, `Outcome`, `PID` を分離する。

## 3. 5.1 世界状態への置換・追加案

現在の \(W_t\) の説明の後に、次を追加する。

> ここでいう \(W_t\) は、現実世界全体そのものではない。\(W_t\) は、AMTが時刻 \(t\) に参照できる地理、行政、郵便、配送、履歴、出典、品質、監査情報を含む住所意味論的状態である。未登録の地物、未知の行政変更、未取得の配送制約は \(W_t\) に含まれない場合がある。

狙い:

完全世界モデルのように読まれる危険を避ける。

## 4. 5.2 住所可能実体集合への追加案

5.2の \(X_t\) 定義の後に、次を追加する。

> 実務上は、理論上存在する住所可能実体集合 \(X_t^{world}\) と、AMTがデータ・出典・推定器により扱える既知実体集合 \(X_t^{known}\) を区別する。
>
> \[
> X_t^{known} \subseteq X_t^{world}
> \]
>
> 候補生成、評価、PID発行は通常 \(X_t^{known}\) 上で行われる。真の対象が \(X_t^{known}\) または候補集合に含まれない場合、後段の評価関数はその対象を回復できない。

狙い:

第3章の「全世界完全カバーではない」限定と、第6章の候補欠落定理を第5章へ反映する。

## 5. 5.3 表面表現集合と観測空間への修正案

現在の \(O_t:X_t\to Y_t\) は、証明には便利だが現実モデルとしては狭い。次のように補強するとよい。

追加文:

> 実務上、一つの実体は複数の表面表現や観測を持ち得る。したがって、観測を関数としてだけでなく、関係または集合値写像として扱うことがある。
>
> \[
> Obs_t \subseteq X_t \times Y_t
> \]
>
> または
>
> \[
> O_t:X_t\to 2^{Y_t}
> \]
>
> 第6章の不可能性定理では、証明を簡潔にするため、一つの観測を返す縮約モデル \(O_t:X_t\to Y_t\) を用いる。

狙い:

理論証明の単純モデルと、現実の多観測モデルを両立する。

## 6. 5.3 に解析写像を追加

表面表現から観測への写像を追加する。

追加文:

> 表面表現 \(s\in S_t\) は、そのまま候補集合になるわけではない。まず解析写像によって観測へ変換される。
>
> \[
> \alpha_t:S_t\to Y_t
> \]
>
> \(\alpha_t\) は、正規化、トークン化、言語推定、郵便照合、地図候補取得、座標変換、出典付与、履歴照合などを含む。

狙い:

第4章の表面表現と、第7章の写像連鎖をつなぐ。

## 7. 5.5 候補生成写像への修正案

現在の

\[
\Gamma_{c,t}:S_t\to 2^{X_t}
\]

は分かりやすいが、5.3の解析写像を入れるなら次のように書くとより正確である。

\[
\Gamma_{c,t}:Y_t\to \mathcal{P}_{fin}(X_t^{known})
\]

説明文:

> ここで \(\mathcal{P}_{fin}(X_t^{known})\) は、既知実体集合の有限部分集合を表す。実装上の候補生成器は、無限集合ではなく有限の候補リストを返す。候補生成の主目的は、初段で真候補を落とさないことである。

狙い:

Leanのリストモデル、実装の候補リスト、理論上の冪集合を整合させる。

## 8. 5.6 構造的非類似度への限定文

5.6末尾に、次を追加する。

> \(D_{c,t}\) は、数学的距離空間の距離であるとは限らない。本稿では、非負値を返す構造的非類似度として用いる。必要に応じて、対称化された非類似度、方向付き非類似度、文脈別非類似度を区別する。

狙い:

距離公理を不用意に仮定しない。Leanの `asymmetric_dissimilarity_not_symmetric` と整合する。

## 9. 5.7 クラスタ分割への追加案

5.7末尾に、次を追加する。

> クラスタは同一実体を断定するものではなく、同一参照クラスである可能性を持つ候補群である。クラスタリングは後段の評価関数と品質ゲートを必要とする。したがって、クラスタに入ったことはPID発行の十分条件ではない。

狙い:

クラスタと確定参照を混同しない。

## 10. 5.8 評価関数と解決結果型への修正案

評価関数の説明に、次を追加する。

> 評価関数は最大値を返すだけでは十分でない。安全な選択には、最良候補の品質が閾値を超えること、次点候補との分離マージンが十分であること、証拠の鮮度が十分であること、リスクが許容範囲内であることが必要である。

解決結果型は、より抽象的に次のように書くと後続章で使いやすい。

\[
\mathcal{R}(A)=
\{\mathrm{resolved}(a)\mid a\in A\}
\cup
\{\mathrm{ambiguous},\mathrm{unresolved},\mathrm{rejected}\}
\]

説明文:

> \(A\) は文脈に応じて、候補実体集合、クラスタ集合、参照クラス集合のいずれにもなり得る。PID発行の場合、`resolved` の対象は単なる表面文字列ではなく、発行可能な参照対象である。

狙い:

`resolved(x)` が実体だけに固定されすぎるのを防ぐ。

## 11. 5.9 履歴グラフへの追加案

5.9末尾に、次を追加する。

> 履歴グラフには、公開監査用にappend-onlyで保存される部分と、訂正、失効、秘匿化、法的削除要求に対応する運用上の部分を分ける必要がある。AMTの理論では、少なくとも参照の継承、分割、統合、失効、再発行を表せる構造が必要である。

狙い:

履歴保存則を使いつつ、現実の訂正・失効にも対応できる余地を残す。

## 12. 5.10 PIDへの修正案

5.10に次を追加する。

> PIDは、住所文字列の単純なハッシュではない。PIDは、候補生成、クラスタリング、評価、未解決判定、履歴更新、品質しきい値、鮮度、リスク、監査可能性を通過した参照対象に対して発行される。

さらに、PID一意性について次を追加する。

> 抽象モデルでPID割当が注入的である場合、異なる参照対象が同じPIDを持たないことを証明できる。一方、有限ビットのハッシュベースPIDでは、絶対的な無衝突性ではなく、発行数とビット長に基づく衝突リスク上界として扱う。

狙い:

PIDを単なる文字列ハッシュと誤解されないようにする。

## 14. 第5章の推奨結論

第5章末尾に、次の結論を置くとよい。

> 本章で導入した記法により、住所写像論は、表面表現を直接実体へ対応させる単純な住所正規化ではなく、観測、候補、非類似度、クラスタ、評価、保留、履歴、PID発行を含む時刻・文脈依存の参照理論として定式化される。後続章の不可能性定理、写像連鎖、候補生成、履歴グラフ、PID監査は、この形式的準備に基づく。

## 15. 採用判断

第5章は今の構成のままでよい。ただし、次の八点を反映すると、かなり専門的な論文として強くなる。

1. 記法表を章冒頭に置く。
2. \(W_t\) を「AMTが参照可能な住所意味論的状態」と限定する。
3. `X_t_world` と `X_t_known` を分ける。
4. `Obs_t subset X_t x Y_t` または `O_t: X_t -> 2^Y_t` を導入する。
5. 表面表現から観測への `alpha_t: S_t -> Y_t` を導入する。
6. 候補生成を `Gamma_{c,t}: Y_t -> finite-powerset(X_t_known)` として書く。
7. 解決結果型を抽象型 `R(A)` として再定義する。
8. PID一意性を注入モデルと有限ビット衝突リスクモデルに分ける。

この編集により、第5章は後続章を支える正確な形式的準備になる。
