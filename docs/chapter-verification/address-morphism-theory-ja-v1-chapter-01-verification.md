## 3. セクション別検証

## 3.1 1.1 住所は文字列ではない

この節の主張は第1章の中で最も強く支持できる。Leanでは、観測が非単射である場合、同一観測から真の対象を無条件に完全復元する解決器は存在しない、という形が形式化されている。さらに、正規化が複数の異なる対象を同じ正規化値へ潰す場合、正規化結果だけでは完全解決できないことも示されている。

本文では「住所は文字列ではない」と言い切ってよい。ただし、その意味は「文字列入力は住所参照の観測であり、対象そのものではない」という意味に限定する必要がある。「文字列は不要である」ではない。文字列は候補生成、検索、監査、表記、利用者入力の重要な証拠である。

推奨表現:

> 住所文字列は住所参照の観測であり、対象そのものではない。観測が非単射である限り、文字列だけから対象の真の同一性を無条件に決定することはできない。

## 3.2 1.2 住所は座標でもない

この節も支持できるが、表現は少し精密化すべきである。Leanでは、同じ地表射影を持つ複数の垂直参照対象を、地表射影だけから同時に復元できないことが形式化されている。これは、階、部屋、入口、地下、屋上、宅配ロッカーのような垂直参照層を導入する必要性を支える。

一方で、「座標は住所ではない」とだけ書くと、座標の重要性を過小評価して見える。第1章では、座標を否定するのではなく、座標を証拠の一つに位置付けるべきである。

推奨表現:

> 座標は住所解決における強力な証拠である。しかし、座標は住所参照の全意味を含まない。特に、二次元座標への射影は垂直方向、入口、利用目的、制度的履歴を失う。

## 3.3 1.3 住所は到達と参照のための社会的圧縮である

この節は面白く、論文の個性になる。ただし、現時点では「定理」ではなく「理論的視点」または「作業仮説」として扱うのが安全である。Leanでは、非単射な圧縮写像に完全復号器は存在しないという一般形は形式化されている。しかし、住所全体が社会的圧縮であることを経験的に証明するには、国別住所体系、郵便番号、Plus Codes、AGID/AOID、自然地名などを比較する情報量分析が必要になる。

したがって、第1章では導入的主張として残し、第3章または情報理論章で数理化するのがよい。

推奨表現:

> 本稿では、住所を巨大な地理的・社会的実体空間を人間と制度が扱える単位へ圧縮した表現として捉える。この圧縮は有用であるが、一般に損失を伴う。そのため、住所解決は圧縮表現の安全な展開問題として定式化される。

## 3.4 1.4 郵便住所を超える住所的対象

この節は実装/GIS検証の方向と合っている。道路、橋、川、滝、湖、島、山、砂漠、湿地、氷河、洞窟、谷、遺跡、世界遺産などを「住所的対象」として扱うのは、住所写像論の拡張性を示すために有効である。

ただし、ここでは「住所可能性」と「郵便配送可能性」を明確に分離する必要がある。自然地理や文化財は参照可能でも、郵便配送可能とは限らない。さらに、地図ソースごとの命名、境界、精度、ライセンス、更新頻度が異なるため、完全性を主張してはいけない。

推奨表現:

> 住所写像論の対象は、郵便受取可能な建物だけではない。ただし、郵便配送可能性、地理的参照可能性、文化的名称としての参照可能性は異なる属性であり、同一視しない。

## 3.5 1.5 解決できないことを出力できる理論が必要である

この節は最も強く残せる。Leanでは、`ambiguous`, `unresolved`, `rejected` が特定の対象を解決しないこと、誤った対象を発行しないこと、発行条件が満たされないときに `unresolved` へ保留することが形式化されている。

したがって、第1章の結論は「住所写像論は万能解決器ではなく、安全な非発行を含む解決理論である」とするのがよい。

推奨表現:

> 住所写像論の安全性は、正しく解決する能力だけでなく、証拠が不足するときに解決しない能力によって支えられる。

## 4. 第1章に残してよい強い主張

1. 住所文字列は対象そのものではなく、対象を指すための観測である。
2. 非単射観測の下では、無条件完全住所解決器は存在しない。
3. 二次元座標だけでは垂直参照対象を一般に区別できない。
4. `ambiguous`, `unresolved`, `rejected` は安全な非発行状態である。
5. PID発行は候補返却より強い操作であり、発行条件、品質、鮮度、衝突リスクを分けて監査する必要がある。

## 5. 弱めるべき主張

1. 「住所は社会的圧縮である」は、現時点では定理ではなく作業仮説として書く。
2. 「郵便住所を超える全対象を扱える」は、対象種別とデータソースの範囲を明記する。
3. 「住所は座標ではない」は、座標を否定する表現ではなく、座標を証拠の一つに位置付ける表現へ変える。
4. 「世界中の地物を認識できる」は書かない。代わりに、登録済みソースで検証可能な範囲を増やす、と書く。

## 7. 最終判定

第1章は、このまま母艦原稿の導入として使える。ただし、現在の書き方は少し広く言い切っている箇所がある。試作としては、次の方針で編集するのが最も安全である。

1. 「文字列ではない」「座標ではない」は、証拠と対象の分離として明確化する。
2. 「社会的圧縮」は定理ではなく、以後のモデル化へつなぐ導入仮説として置く。
3. 自然地理・文化財・世界遺産は、郵便配送可能性ではなく参照可能性として扱う。
4. 第1章の結論は、万能解決ではなく安全な非発行へ寄せる。

この構成なら、第1章は検証済み主張と未検証仮説を混ぜずに、論文全体の入口として十分に機能する。
