# 北米・カリブ海のポリゴン品質

## 形状と判定範囲の検査

AGID の地理データを変更するプルリクエストでは、北米・中米・カリブ海の詳細判定に使うポリゴンを検査する。外周と穴の閉じ方、自己交差、座標値、外接矩形、重複図形を調べる。各判定範囲の内側では、陸と水が面積をもって重なると検査が失敗する。岸や国境で線・点を共有する図形は許容する。同じ優先度の判定範囲が重なって結果が読み込み順に左右されるケースも検出する。

海岸線と行政界は別の資料から得るため、行政界が水面を含む場合や、陸地の所属を確定できない場合がある。異なる地域コードの重なりは件数を報告する。現地の海岸線との位置のずれや島の取りこぼしはこの形状検査だけでは測れないため、地点ごとの陸水・所属判定も回帰テストで確認する。

リポジトリのルートで次を実行すると、地理データの CI と同じ形状検査を再現できる。

```sh
python -m pip install 'shapely==2.1.2'
python scripts/test-americas-survey-polygons.py
python scripts/verify-americas-survey-polygons.py
```

## 収録した地形

| 地域 | 対象 | 照合に使った資料 |
| --- | --- | --- |
| 米国・カナダの五大湖とセントローレンス川 | スペリオル湖のアイル・ロイヤル島にあるシスキウィット湖と、その中のライアン島。ピリー島北端のヘンリー湖。セントローレンス川のハート島 | 米国国勢調査局 TIGER/Line 2025、オンタリオ州の五大湖島嶼台帳・Ontario Hydro Network |
| 米国太平洋岸・大西洋岸 | アルカトラズ島とサンフランシスコ湾、エルクホーン・スルーとモスランディング港、チェサピーク湾のタンジア島 | TIGER/Line 2025 の水域面と道路、米国魚類野生生物局の National Wetlands Inventory。干出・冠水を繰り返すと記録された場所は確定を保留する。河口の水面を横断する道路では、橋上と橋下を判別できない範囲を要確認とする |
| メキシコの太平洋岸・カリブ海側 | カリフォルニア湾のバジェナ島・ガジョ島・ガジナ島、プンタ・バンダ河口の砂州、ムヘレス島の潟湖マカスとサリナ・グランデ | INEGI の2025年12月版 Marco Geoestadístico、島嶼目録、CONANP・SEMARNATの地域資料 |
| プエルトリコ・米領ヴァージン諸島 | クレブリタ島のラグナ・デ・モリノ、クレブラ島のラグナ・デル・フラメンコ、セント・ジョン島のソルト・ポンド、セント・クロイ島のグレート・ポンド | TIGER/Line 2025 の水域面と対象の水域識別子。島の陸地には住所地域 PR または VI と主権国 US を保持する |
| 仏領グアドループ | プティット・テール諸島テール・ド・バ島の塩性潟湖と隣接する陸地・海面。陸地では地域 GP と主権国 FR を保持する | IGNの行政界・水域面、自然保護区の管理資料 |

各区域で ESA WorldCover 2020 v100 と 2021 v200 の10 m土地被覆を照合する。水路図・境界資料と両年の観測で陸または水を確認できた部分を収録し、季節変動や資料のずれが残る場所は要確認とする。内水の分類は塩分を表さない。海とつながるムヘレス島のマカス潟はカリブ海側の海水面として扱う。10 m は衛星資料の画素の公称サイズで、海岸線の位置精度やGPS精度を保証する値ではない。

出典と版は個々の区域の `evidenceUrls`、`version`、`attribution` に記録している。出典の外周に余白を持たせてから使用範囲を絞り、地図の切断線が現地の岸として扱われるのを防ぐ。ピンが同一座標でも、測位誤差が岸をまたぐ場合には水面・陸地の確定を保留する。

## 原典からの再生成

Python 3.11以降、GDALのPythonバインディング、NumPy、Shapely 2を使用する。リポジトリのルートで次を実行する。各生成器は提供元の版に対応するチェックサムを照合する。

```sh
python3 scripts/build_na_lakes_polygon_detail.py /tmp/agid-lakes-input --download
python3 scripts/build_na_estuary_polygon_detail.py /tmp/agid-estuary-input --download
python3 scripts/build_na_mexico_polygon_detail.py --input-directory /tmp/agid-mexico-input
python3 scripts/build_caribbean_polygon_detail.py /tmp/agid-caribbean-input --download
python3 scripts/build_antilles_polygon_detail.py /tmp/agid-antilles-input --download
npm run verify:agid-islands
```

同じ測位誤差でも岸からの距離によって結果は変わる。モスランディングでは沖合（36.806347, -121.790802）と潮下帯の水路（36.811028, -121.782287）を海域に、干潟（36.812376, -121.788351）と道路橋（36.809938, -121.784722）を要確認に分類する。

15区域の8,542地点について、Shapelyが出した結果をAGIDの実装と照合した。格子状に選んだ7,935地点に加え、ポリゴンの内側、境界の頂点、陸地内の穴も含めた。地表、島名、地域・主権国、海域、要確認の扱いは全地点で一致した。この件数は同じ地図データを2通りの方法で読んだ結果の比較である。

所在地や水域を資料で確認した50地点（島16、本土3、水域24、要確認7）を、変更前と変更後の同一座標で比較した。地表、所属候補、島・本土、水域の種類、確定可否の一致は18/50から50/50に、島の名前まで含めた一致は11/50から50/50になった。ピンと発行したIDのセルの双方で同じ結果を得た。高精細オフライン地図の確認地点122件もすべて通過した。
