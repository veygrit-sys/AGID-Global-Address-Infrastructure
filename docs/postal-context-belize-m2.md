## Outcome

Belize does not currently require postal codes in the reviewed primary evidence. The current UPU General Addressing Issues publication contains a September 2025 Universal DataBase table that explicitly lists Belize among countries not requiring postal codes. The UPU Belize country sheet edition 05/2021 shows an address with street, Belize City locality and country lines but no postcode. Current Belize Postal Service regular-mail instructions require a clearly printed destination address, while its P.O.-Box page says the private box number forms part of the address; neither page publishes a postcode requirement or assignment.

M2 cannot be achieved by inventing a ZIP, relabelling a P.O. Box number, copying an address example or merely proving absence. It still requires a real current assignment denominator and an eligible area artifact.

## Area and app gate

No official, derived or virtual rights-cleared BZ postcode Polygon/MultiPolygon artifact exists because no current postcode assignment anchors one. Districts, cayes, cities, towns, villages, localities, post offices, delivery areas, routes, P.O. Boxes, addresses, buildings, parcels, Points, buffers, hulls, Voronoi/raster cells, models and AGID cells are not postal areas and were not promoted.

The real BZ application path is therefore deliberately disabled. There is no valid BZ postcode input or eligible BZ postal geometry for the API to return, fit or draw with a translucent fill and clear outline. Loading, no-match, multiple, API-failure, invalid-geometry, clear and re-search behavior exists in the shared application capability, but shared code and synthetic fixtures are not BZ M2 evidence. Browser E2E was not run because it would test only shared or synthetic behavior.

## Rights and privacy boundary

The UPU disclaimer permits use or reproduction of website information subject to its conditions and source acknowledgement. Its copyright page leaves reproduction and database restrictions applicable. These pages are not a bulk postcode assignment or geometry licence. The reviewed Belize Postal Service pages publish service instructions but no resource-specific assignment/geometry dataset or compatible AGID processing, derivation, redistribution and public-serving permission.

No provider was contacted, no registration or authentication was attempted, no terms or contract were accepted, no payment was made and no protected address, recipient, customer, P.O.-Box holder, delivery, property, cadastral or land-right row was queried.
