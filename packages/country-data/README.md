# @agid/country-data

Country and territory address-format metadata, official or reusable OSS source
evidence, quality gates, signatures, and generated child-pack inputs.

Large geometry and private operational data remain external. Postal lookup
promotion requires explicit rights, version, freshness, coverage, correction,
and reproducibility evidence.

This workspace exposes the lightweight Postal Context resolver bridge. Country
repositories publish immutable, digest-pinned releases; they do not become
runtime source dependencies of the AGID application.
