# Data And License Notes

This repository profile is for theory and publication materials, not an address
dataset.

- Paper and documentation license: inherit the seed repository policy in
  `reports/address-morphism-theory-review/LICENSE-PAPERS.md`.
- Code license: inherit the seed repository policy in
  `reports/address-morphism-theory-review/LICENSE`.
- Data package status: none.
- External source status: cite public references in papers and notes; do not
  vendor external datasets into this profile.

Publication safety: synthetic examples are allowed, but private address,
recipient, witness, proof-secret, private-key, production credential, and raw
carrier payload material are not allowed.
