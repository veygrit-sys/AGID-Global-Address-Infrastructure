# address-spatial-information

Local repository starter for Address Spatial Information (住所空間情報学).

## Scope

spatial relations among addresses, features, grids, entrances, and delivery points

## Owns

- address-to-geometry relation models
- grid and coordinate comparison methodology
- spatial uncertainty notes
- synthetic spatial fixtures

## Boundary

Spatial proximity does not prove address identity or carrier reachability.

This is domain 5 in the spatial and structural group. It is local-only and does not create a remote repository.

## Promotion

Before any remote creation, add reviewed public research material, name a maintainer or review owner, complete source and license review, and run the repository creation preflight.
