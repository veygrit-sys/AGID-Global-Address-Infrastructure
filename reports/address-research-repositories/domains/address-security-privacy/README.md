# address-security-privacy

Local repository starter for Address Security and Privacy Engineering (住所セキュリティ・プライバシー工学).

## Scope

minimal disclosure, access control, threat modeling, and privacy-preserving proofs

## Owns

- address privacy threat models
- minimal-disclosure methodology
- access-control and revocation models
- public proof-boundary specifications

## Boundary

A privacy design does not make a person anonymous or establish a cryptographic security proof.

This is domain 13 in the societal implementation group. It is local-only and does not create a remote repository.

## Promotion

Before any remote creation, add reviewed public research material, name a maintainer or review owner, complete source and license review, and run the repository creation preflight.
