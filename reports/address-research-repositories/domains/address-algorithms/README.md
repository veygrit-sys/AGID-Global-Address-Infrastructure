# address-algorithms

Local repository starter for Address Algorithms (住所アルゴリズム論).

## Scope

parsing, normalization, candidate generation, matching, and error correction

## Owns

- algorithm specifications
- evaluation methodology
- synthetic benchmark definitions
- algorithmic non-claim reviews

## Boundary

An algorithmic score does not establish a correct address or authorize an automated decision.

This is domain 10 in the computing group. It is local-only and does not create a remote repository.

## Promotion

Before any remote creation, add reviewed public research material, name a maintainer or review owner, complete source and license review, and run the repository creation preflight.
