# address-ontology

Local repository starter for Address Ontology (住所存在論).

## Scope

foundational concepts for addressable entities, places, delivery points, and institutions

## Owns

- addressable entity taxonomy
- place and delivery-point distinction
- address kind vocabulary
- ontology-level non-claim reviews

## Boundary

An ontology does not prove a place exists, is current, or is deliverable.

This is domain 1 in the address foundations group. It is local-only and does not create a remote repository.

## Promotion

Before any remote creation, add reviewed public research material, name a maintainer or review owner, complete source and license review, and run the repository creation preflight.
