# address-identity

Local repository starter for Address Identity and Identifiers (住所同一性・識別子論).

## Scope

persistent identifiers, referent identity, and split or merge continuity

## Owns

- identifier lifecycle models
- referent identity criteria
- split and merge identifier rules
- identifier non-claim reviews

## Boundary

A persistent identifier does not prove ownership, residency, or current reachability.

This is domain 8 in the spatial and structural group. It is local-only and does not create a remote repository.

## Promotion

Before any remote creation, add reviewed public research material, name a maintainer or review owner, complete source and license review, and run the repository creation preflight.
