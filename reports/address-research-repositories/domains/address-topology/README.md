# address-topology

Local repository starter for Address Topology (住所階層・位相学).

## Scope

containment, adjacency, access, and overlapping administrative or delivery structures

## Owns

- address containment relations
- adjacency and access models
- boundary-overlap methodology
- topological counterexamples

## Boundary

A containment or adjacency relation does not establish a current delivery route.

This is domain 6 in the spatial and structural group. It is local-only and does not create a remote repository.

## Promotion

Before any remote creation, add reviewed public research material, name a maintainer or review owner, complete source and license review, and run the repository creation preflight.
