# address-semantics

Local repository starter for Address Semantics (住所意味論).

## Scope

purpose-dependent meaning of address components and delivery instructions

## Owns

- address component semantics
- purpose-dependent interpretation models
- delivery-instruction boundaries
- semantic ambiguity studies

## Boundary

A semantic interpretation does not establish legal authority or recipient intent.

This is domain 4 in the address foundations group. It is local-only and does not create a remote repository.

## Promotion

Before any remote creation, add reviewed public research material, name a maintainer or review owner, complete source and license review, and run the repository creation preflight.
