# address-ux-social-implementation

Local repository starter for Address UX and Social Implementation (住所UX・社会実装学).

## Scope

human input, review, sharing, accessibility, and equitable address use

## Owns

- address input and confirmation research
- accessibility and inclusion methodology
- human-in-the-loop design studies
- social-impact non-claim reviews

## Boundary

A usable interface does not prove that an entered address is correct or safe to disclose.

This is domain 16 in the societal implementation group. It is local-only and does not create a remote repository.

## Promotion

Before any remote creation, add reviewed public research material, name a maintainer or review owner, complete source and license review, and run the repository creation preflight.
