# address-temporal-information

Local repository starter for Address Temporal Information (住所時間情報学).

## Scope

address lineage, validity periods, and historical change events

## Owns

- bitemporal address models
- lineage event vocabulary
- rename split and merge methodology
- historical-address non-claim reviews

## Boundary

A lineage edge does not prove uninterrupted social, legal, or occupancy identity.

This is domain 7 in the spatial and structural group. It is local-only and does not create a remote repository.

## Promotion

Before any remote creation, add reviewed public research material, name a maintainer or review owner, complete source and license review, and run the repository creation preflight.
