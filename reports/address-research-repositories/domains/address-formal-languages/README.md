# address-formal-languages

Local repository starter for Address Formal Languages (住所形式言語学).

## Scope

address grammars, tokenization, parsing, rendering, and multilingual notation

## Owns

- address grammar profiles
- syntactic parsing contracts
- multilingual notation studies
- synthetic parser fixtures

## Boundary

A syntactically valid expression is not evidence of identity, existence, or deliverability.

This is domain 3 in the address foundations group. It is local-only and does not create a remote repository.

## Promotion

Before any remote creation, add reviewed public research material, name a maintainer or review owner, complete source and license review, and run the repository creation preflight.
