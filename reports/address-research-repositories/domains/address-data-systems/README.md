# address-data-systems

Local repository starter for Address Data Systems (住所データ構造・データベース論).

## Scope

typed schemas, address databases, provenance, and distributed data models

## Owns

- address schema research
- database and index methodology
- provenance and merge models
- public data-system specifications

## Boundary

A database schema does not make source data complete, licensed, or authoritative.

This is domain 9 in the computing group. It is local-only and does not create a remote repository.

## Promotion

Before any remote creation, add reviewed public research material, name a maintainer or review owner, complete source and license review, and run the repository creation preflight.
